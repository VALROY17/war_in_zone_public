✅ Гайд: чек-лист релиза мода

Перед тем как публиковать свой мод, пройдите по этому чек-листу. Он составлен на основе типичных ошибок, которые допускают мододелы. Большинство проблем из списка ниже — это 1–2 минуты на исправление, но они могут полностью сломать игру, если их пропустить.

🎯 Что получится в итоге

  • Мод, который работает у других игроков так же, как у вас
  • Отсутствие «кракозябр», пропавших имён, вылетов и зависаний
  • Понятная инструкция для игроков (описание, версия, известные проблемы)
  • Минимум негативных отзывов вида «не работает» или «поломанный мод»

📝 Чек-лист релиза

Проходите по пунктам сверху вниз. Отмечайте галочкой каждый пройденный пункт. Если по какому-то пункту нашли проблему — исправьте и проверьте снова.

🔤 1. Кодировка и формат файлов

⚠️ Самая частая причина «кракозябр»
Файлы должны быть в UTF-8 с BOM. Без BOM кириллица отображается мусором.
  • ☐ Все .ini-файлы сохранены в UTF-8 с BOM (проверяется в Notepad++: Кодировки → должно быть UTF-8-BOM)
  • ☐ Файл messages.csv сохранён в UTF-8 с BOM
  • ☐ Файл Settings.ini сохранён в UTF-8 с BOM
  • ☐ В текстах messages.csv нет символа ; — иначе строка обрывается
  • ☐ В именах файлов и путях нет русских букв и пробелов
  • ☐ В дробных значениях используется запятая, а не точка (например, 1,5, не 1.5)

Подробнее: Кодировка файлов, messages.csv, Советы по моддингу.

📂 2. Структура файлов и папок

  • ☐ Все файлы лежат в правильных папках:
    • Groups/ — файлы группировок
    • ideologies/ — идеологии
    • leaders/ — лидеры
    • upgrades/ — улучшения
    • Buildings/ — постройки
    • Goods/ — товары, оружие, броня
    • Receipts/ — рецепты мастерской
    • RandomEvents/ — случайные события
    • SpecialEvents/ — особые события
    • map/ — файлы карты
  • ☐ Имена файлов без расширения совпадают с техническими названиями в квадратных скобках [] внутри файла
  • ☐ Все файлы изображений существуют по указанным путям
  • ☐ Иконки на карте IconMap — статичные изображения (png, jpg), а не gif (анимация не работает)
  • ☐ Карта (map.bmp / map.png / map.jpg) существует, а map.bt создан редактором карт, а не вручную

Подробнее: Структура сценария, FAQ №8 (форматы изображений).

🔗 3. Связи между конфигами

⚠️ Типичная ошибка — «сирота»
Сущность прописана в одном файле, но не прописана в связанных. Например, лидер существует, но не привязан к группировке.
  • ☐ Группировки — прописаны во всех обязательных секциях:
    • [Group-UnitIndex] — 4 шаблона юнитов
    • [Group-Leaders] — лидер
    • [Group-Advisor] — заместитель со старта
    • [Group-Rules] — 4 внутренних правила
    • [Group-Ideology] — стартовая идеология
    • [Group-Ideology-Percent] — проценты (сумма = 100)
    • [MainZoneFraction] — главная база
    • Хотя бы одна [ZonaX] с Owner=название
    • [Diplomacy] — симметричные отношения со всеми
    • [Advisors] — доступность заместителей
  • ☐ Лидеры: файл есть + прописан в [Group-Leaders] + локализация [Leaders.*].Name
  • ☐ Заместители: секция в Advisors.ini + Fraction=группировка + строка =True в [Advisors] + локализация
  • ☐ Идеологии: файл есть + секция [Название] в каждой группировке, где она может быть основной + процент в [Group-Ideology-Percent] + локализация [Ideologies.*].Name
  • ☐ Постройки и улучшения: файлы существуют + локализация Name и Desc
  • ☐ Товары: используются только существующие имена из Goods/ в параметрах NameResources, Custom-Resource, Name
  • ☐ Дипломатические отношения — симметричны: если A-B=1, то B-A=1

Подробнее: Groups (таблица «Где ещё прописывается группировка»), Ideologies, Leaders, Advisors.

🎨 4. Графика и звуки

  • ☐ Все файлы изображений из параметров Img=, Logo-*=, IconMap=, *-Face= существуют по указанным путям
  • ☐ Для лидеров, заместителей, идеологий достаточно одного базового изображения (состояния движок делает сам)
  • ☐ Для улучшений — достаточно одного Logo-NonActive
  • ☐ Для построек — достаточно одного Logo-NonActive
  • ☐ Иконки группировок на карте — png или jpg, не gif
  • ☐ Звуковые файлы (SoundFXForOwnerFile= и т.п.) существуют
  • ☐ Папка идеологий называется Idealogies (с буквой a) — это историческая особенность движка

⚙ 5. Геймплей и баланс

  • ☐ Условия победы достижимы: игрок может выиграть при разумной игре
  • ☐ Условия поражения реальны: игрок может проиграть
  • ☐ Группировки владеют территориями — нет «висящих в воздухе» фракций
  • ☐ Бонусы не зашкаливают:
    • BonusForSpy, BonusDamage* — разумные значения (±20% обычно достаточно)
    • IdeologyBonus у лидера/заместителя — не больше 5–10% за ход, иначе идеология вытеснит все остальные за 10 ходов
  • ☐ Стоимость улучшений соответствует их силе
  • ☐ Шансы разведки в сумме с бонусами не превышают 100% (иначе всегда успех)
  • ☐ Шанс смерти при поиске артефакта — не слишком высокий, иначе игроки не будут искать

🤖 6. Поведение ИИ

⚠️ Нельзя брать чужой блок ИИ
Параметр AI= у новой группировки должен ссылаться только на Default, None или собственный блок. Чужой блок может содержать Advisor-TargetName, который привязан к конкретной группировке, — это вызовет ошибку.
  • ☐ У каждой группировки корректный параметр AI= в блоке [:main]
  • ☐ В AI.ini нет ссылок на заблокированные улучшения (те, что в ExcludedUpgrades из Settings.ini)
  • ☐ В AI.ini нет ссылок на заблокированные постройки (те, что в ExcludedBuildings)
  • ☐ ИИ-группировки не пытаются назначать заместителей других фракций

Подробнее: AI.ini, Settings.ini.

📖 7. События (Events)

  • ☐ У каждого сюжетного события (Events_Story.ini) указан Zona — без этого событие не сработает
  • ☐ В каждой секции события только один параметр Type
  • ☐ У случайных событий (RandomEvents/) нет параметра Zona — там всегда случайная территория
  • ☐ У всех событий корректный Type (один из 35 сюжетных или 22 случайных)
  • ☐ Для типа ChangeIdeologyPercent параметр CountParam — только положительный
  • ☐ Ивент-флаги используются правильно:
    • Зарезервированные EndVictory / EndLose не используются для своих нужд
    • Проверки EventFlagStatusNeed совпадают с именами флагов в EventFlagResult
  • ☐ Локализация событий есть ([Events_Story.*].Name, .Desc, [RandomEvents.*].Name, .Desc-YES, .Desc-NO)

Подробнее: Events_Story.ini, RandomEvents, Рудименты и «не трогать».

🌐 8. Локализация

  • ☐ Все ключи [Buildings.*].Name и .Desc существуют
  • ☐ Все ключи [Upgrades.*].Name и .Desc существуют
  • ☐ Все ключи [Leaders.*].Name существуют
  • ☐ Все ключи [Advisors.*].Name существуют
  • ☐ Все ключи [Ideologies.*].Name существуют
  • ☐ Все ключи [Groups.*.:main].Name и .Description существуют
  • ☐ Все ключи [Goods.*].Name и .Desc существуют
  • ☐ Ключи ScenarioName, ScenarioDescription, ScenarioVictoryDescription, ScenarioLoseDescription прописаны в messages.csv
  • ☐ В тексте нет запрещённых символов (; в тексте)
  • ☐ Спецсимволы %s, %0:s, || используются правильно

Подробнее: messages.csv.

🎮 9. Тестирование

💡 Минимум — пройти свой мод хотя бы раз
Перед публикацией запустите сценарий, пройдите его за каждую доступную игроку группировку хотя бы на 10–20 ходов. Большинство критических багов находятся уже на этом этапе.
  • ☐ Сценарий запускается без ошибок
  • ☐ Список группировок отображается корректно (названия, логотипы)
  • ☐ Игра за каждую доступную группировку работает
  • ☐ Все окна (найм, строительство, дипломатия, улучшения) открываются без вылетов
  • ☐ Сюжетные события срабатывают на нужных ходах
  • ☐ Условия победы и поражения работают
  • ☐ Боты ведут себя адекватно (не стоят на месте, строят, атакуют)
  • ☐ Условие End-EventFlag-Victory / End-EventFlag-Lose (если используется) — реально достигается или обходится
  • ☐ Нет вылетов при срабатывании особых событий (выброс, пси-излучение)
  • ☐ Окно обучения (если включено) отображается корректно

📦 10. Подготовка к публикации

  • ☐ Укажите версию мода (например, 1.0, 1.1-beta) — это поможет вам и игрокам понимать, какая версия установлена
  • ☐ Напишите описание мода — кратко о чём, для какой версии игры, какие группировки, какие особенности
  • ☐ Сделайте скриншоты карты, ключевых интерфейсов, логотипов группировок
  • ☐ Составьте список известных проблем — то, что вы знаете, но ещё не починили. Игроки оценят честность
  • ☐ Укажите контакты для обратной связи (Discord, почта, страница мода)
  • ☐ Укажите совместимую версию игры (если мод может не работать в более новых/старых версиях)
  • ☐ Приложите инструкцию по установке (куда положить папку сценария, какие настройки включить)
  • ☐ Если мод основан на другом — укажите авторство оригинала

⚠️ Вероятные ошибки при релизе

Мод работает у меня, но не у других игроков

Самая частая причина — файлы сохранены не в UTF-8 с BOM. На вашем компьютере кодировка может подхватиться случайно, а у других — нет.

Решение: откройте каждый файл в Notepad++, Кодировки → Преобразовать в UTF-8-BOM → сохранить.

Вылет при запуске сценария

Возможные причины:

  • Отсутствует файл, на который ссылается параметр (изображение, другой конфиг)
  • Группировка не владеет ни одной территорией и не указана в событиях Invasion
  • В MainZoneFraction указан несуществующий индекс территории
  • В AI.ini ссылка на заблокированное улучшение или постройку
  • Битая строка в messages.csv (например, ; внутри текста)
Вместо имён отображаются технические названия

Игра не нашла локализацию. Проверьте:

  • Ключи в messages.csv совпадают с именами секций/файлов
  • Файл messages.csv в кодировке UTF-8 с BOM
  • Разделитель — точка с запятой ;, а не двоеточие
Боты не действуют или вылетают на своём ходу

Проверьте:

  • Параметр AI= у группировки ссылается на существующий блок
  • В блоке ИИ нет ссылок на заблокированные улучшения (ExcludedUpgrades)
  • В блоке ИИ нет ссылок на заблокированные постройки (ExcludedBuildings)
  • Бот не пытается назначать заместителей чужих фракций
💡 Совет: тестируйте на чистом компьютере
Если есть возможность — попросите друга установить ваш мод и попробовать сыграть. Другой компьютер — другой набор файлов, другая версия игры, другой пользователь. Многие «работает у меня» проблемы так находятся моментально.
