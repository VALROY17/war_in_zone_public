🎲 Гайд: случайное событие

В этом гайде мы добавим в игру новое случайное событие — «Находка боеприпасов». Событие будет добавлять группировке от 100 до 500 единиц боеприпасов (случайное число в диапазоне) на случайной территории.

🎯 Что получится в итоге

  • Новое случайное событие, которое может произойти в любой момент игры
  • Событие происходит на случайной территории (в отличие от сюжетных событий)
  • Добавляет группировке от 100 до 500 единиц боеприпасов (движок сам выбирает число в диапазоне)
  • Не срабатывает у Мутантов и Зомби (у них нет склада)
  • Отображается с иконкой события, иконкой ресурса и звуковым оповещением

📋 Что нужно подготовить

  • Одно изображение для иконки события (формат PNG, размер как у существующих — смотрите в data\gfx\icons\events\)
  • Одно изображение для иконки ресурса (в нашем случае — иконка боеприпасов, которая уже есть в data\gfx\icons\goods\Supplies.png)
  • Один звуковой файл (формат MP3 или OGG, опционально)

📝 Пошаговая инструкция

Шаг 1. Создайте файл события

В папке вашего сценария создайте папку RandomEvents/ (если её ещё нет), а внутри — файл FindSupplies.ini. Имя файла без расширения = техническое название события, которое используется в локализации.

За основу возьмём реальный конфиг event2.ini из стандартного сценария игры (добавление дешёвых артефактов). Вот его точное содержимое:

[Main]
Type=AddResources
Img=gfx\icons\events\2.png
TargetResourceImg=gfx\icons\goods\Arts1.png
CountMin=1
CountMax=5
SoundFXForOwner=True
SoundFXForOwnerFile=sfx\events\message.mp3
NameResources=LowArts
NotWorkFractions=Mutants,Zombie

Скопируйте этот текст в свой новый файл FindSupplies.ini и внесите следующие изменения:

[Main]
Type=AddResources
Img=gfx\icons\events\find_supplies.png
TargetResourceImg=gfx\icons\goods\Supplies.png
CountMin=100
CountMax=500
SoundFXForOwner=True
SoundFXForOwnerFile=sfx\events\message.mp3
NameResources=Supplies
NotWorkFractions=Mutants,Zombie
📌 Что мы изменили по сравнению с прототипом
  • Img=gfx\icons\events\find_supplies.png — путь к нашей иконке события
  • TargetResourceImg=gfx\icons\goods\Supplies.png — путь к иконке ресурса (боеприпасы, уже существует в стандартных конфигах)
  • CountMin=100, CountMax=500 — диапазон: игра сама выберет случайное число от 100 до 500 при срабатывании события
  • NameResources=Supplies — техническое название ресурса из папки Goods/ (уже существует в стандартном сценарии)
  • NotWorkFractions=Mutants,Zombie — событие не сработает у Мутантов и Зомби (у них нет склада)
💡 Случайность значения

Параметры CountMin и CountMax задают диапазон. При срабатывании события движок сам выбирает случайное число внутри этого диапазона. Если хотите фиксированное число — укажите одинаковые значения: CountMin=100 и CountMax=100.

⚠️ Событие происходит на случайной территории

У случайных событий нет параметра Zona — они всегда происходят на случайно выбранной территории. Это главное отличие от Events_Story.ini, где каждое событие привязано к конкретной территории.

Если вам нужно событие на конкретной территории — используйте сюжетные события, а не случайные.

Шаг 2. (Необязательно) Положите иконки

Если хотите свою иконку события — поместите файл find_supplies.png по пути gfx\icons\events\find_supplies.png в папке вашего сценария.

💡 Если своей иконки пока нет
Можно временно использовать иконку существующего события. Например, укажите Img=gfx\icons\events\2.png — движок возьмёт иконку из стандартного набора событий.

Шаг 3. Добавьте локализацию в messages.csv

Откройте messages.csv вашего сценария и добавьте три строки — название события и два варианта описания:

[RandomEvents.FindSupplies].Name;Находка боеприпасов
[RandomEvents.FindSupplies].Desc-YES;Наши бойцы обнаружили тайник с боеприпасами! Найдено: %0:s единиц.
[RandomEvents.FindSupplies].Desc-NO;Наши бойцы обыскали территорию, но не нашли ничего полезного.
⚠️ Почему два варианта описания

Параметры Desc-YES и Desc-NO работают по условию:

  • Desc-YES — срабатывает, когда событие смогло отработать. Например, если у группировки есть ресурсы, к которым обращено событие (находка, кража)
  • Desc-NO — срабатывает, когда событие не смогло отработать. Например, если ресурсов нет и красть нечего

В нашем случае Desc-YES — когда боеприпасы действительно найдены, а Desc-NO — если по какой-то причине событие не сработало.

Спецсимвол %0:s в Desc-YES автоматически подставит число найденных боеприпасов (то, что выбрал движок в диапазоне 100–500).

⚠️ Формат ключа

Ключ в messages.csv должен совпадать с именем файла события без расширения. У нас файл называется FindSupplies.ini, значит ключ — [RandomEvents.FindSupplies].

Регистр значения не имеет ([RandomEvents.FindSupplies] и [RandomEvents.findsupplies] работают одинаково), но рекомендуется писать так же, как имя файла — это упрощает поиск по файлу messages.csv.

Разделитель между ключом и текстом — точка с запятой ;. Внутри самого текста символ ; использовать нельзя — строка оборвётся.

Шаг 4. Включите случайные события в Settings.ini (если нужно)

Случайные события включаются и отключаются через Settings.ini в параметрах:

[Main]
; ...
EventsRandomDefault=True        ; ← состояние по умолчанию в меню (True = включены)
EventsRandomCanChange=True      ; ← может ли игрок отключить их перед стартом
; ...
💡 Обычно это уже настроено

В стандартном сценарии эти параметры уже установлены в True. Вам нужно их править только если вы хотите по умолчанию отключить случайные события или запретить игроку их включать.

Шаг 5. Сохраните все файлы в правильной кодировке

  • RandomEvents/FindSupplies.ini — UTF-8 с BOM
  • messages.csv — UTF-8 с BOM
  • Settings.ini (если правили) — UTF-8 с BOM

Подробнее про кодировку: «Кодировка файлов».

✅ Проверка результата

  1. Запустите игру и начните свой сценарий
  2. Перед стартом убедитесь, что в меню настроек случайные события включены
  3. Сыграйте несколько ходов — случайные события срабатывают не каждый ход, так что может потребоваться подождать
  4. Когда событие сработает — убедитесь, что:
    • Отображается корректное название («Находка боеприпасов»)
    • Показывается иконка события и иконка ресурса
    • Текст описания содержит число найденных боеприпасов (100–500)
    • Воспроизводится звук (если указан)
    • На складе группировки действительно прибавились боеприпасы

⚠️ Вероятные ошибки

Событие не срабатывает никогда
  • Проверьте, что файл FindSupplies.ini лежит в папке RandomEvents/
  • Проверьте Settings.ini — параметр EventsRandomDefault должен быть True
  • Убедитесь, что игрок не отключил случайные события в меню перед стартом
Вместо названия — техническое имя «FindSupplies»

Игра не нашла локализацию. Проверьте:

  • Ключ точно [RandomEvents.FindSupplies].Name (именно RandomEvents, а не StoryEvents — это разные типы событий)
  • Разделитель — точка с запятой ;
  • В тексте нет символа ;
  • messages.csv сохранён в UTF-8 с BOM
Событие срабатывает у Мутантов или Зомби

У этих группировок нет склада, поэтому событие добавления ресурсов у них не работает. Проверьте, что в конфиге указан параметр:

NotWorkFractions=Mutants,Zombie

Если нужно исключить другие группировки — добавьте их через запятую.

Движок выдаёт ошибку на загрузке
  • Проверьте, что Type — один из 22 допустимых типов (см. справку RandomEvents)
  • Проверьте, что все обязательные параметры для выбранного типа указаны. Для AddResources обязательны: NameResources, CountMin, CountMax, TargetResourceImg
  • Проверьте, что NameResources ссылается на существующий ресурс из папки Goods/
💡 Нюанс: 22 типа событий

Движок поддерживает ровно 22 типа случайных событий — это жёсткий лимит. Создать новый тип нельзя, только использовать один из существующих: AddResources, RemoveResources, AddUnits, Invasion, ChangeLeader, ChangeAdvisor, Build, Destroy и другие.

Полный список и обязательные параметры для каждого типа: справка RandomEvents.

💡 Нюанс: случайные события vs сюжетные

Случайные события и сюжетные (Events_Story.ini) — это разные механики:

  • Случайные — происходят на случайной территории, в случайное время, без привязки к ходу. Не имеют ивент-флагов
  • Сюжетные — привязаны к конкретной территории и ходу, поддерживают ивент-флаги и проверочные типы

Если вам нужен сюжет с условиями и ветвлением — используйте Events_Story.ini, а не RandomEvents.

🔗 Связанные разделы справки

  • RandomEvents — полное описание всех параметров и 22 типов событий
  • Events_Story.ini — сюжетные события (35 типов, привязка к территории)
  • SpecialEvents — глобальные механики (выброс, пси-излучатель)
  • Settings.ini — EventsRandomDefault, EventsRandomCanChange
  • messages.csv — формат локализации, спецсимволы %s
  • Лимиты движка — 22 типа захардкожены, добавить новый нельзя
  • Goods — технические названия ресурсов для NameResources
  • Кодировка файлов — UTF-8 с BOM
