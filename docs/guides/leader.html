👑 Гайд: новый лидер

В этом гайде мы добавим в игру нового лидера для группировки Одиночки — «Медведь». Это опытный командир, который усиливает разведку и защищает территории группировки.

⚠️ Почему это «сложно», а не «очень легко»
Лидер — это не просто файл с бонусами. Нужно:
  • Создать файл лидера в папке leaders/
  • Привязать лидера к группировке через Main.ini → [Group-Leaders]
  • Добавить локализацию в messages.csv
  • Создать портрет лидера
В отличие от заместителя (у которого привязка к фракции через параметр Fraction), у лидера привязка задаётся через Main.ini.

🎯 Что получится в итоге

  • Новый лидер «Медведь» станет доступен для группировки Одиночки
  • Даёт +10% к успеху своей разведки и −5% к успеху вражеской
  • Продвигает идеологию Сталкерство (+3% каждый ход)
  • Увеличивает шанс поиска артефактов на 5%

📋 Что нужно подготовить

  • Одно изображение для портрета лидера (формат PNG или GIF, размер как у существующих — смотрите в data\gfx\icons\leaders\)

📝 Пошаговая инструкция

Шаг 1. Создайте файл лидера

В папке вашего сценария создайте подпапку leaders/ (если её ещё нет), а внутри — файл Leader-Medved.ini. Имя файла без расширения = техническое название лидера.

За основу возьмём реальный конфиг Leader-1-COP.ini из стандартного сценария игры. Вот его точное содержимое:

[main]
Img=gfx\icons\leaders\Stalkers-COP.gif
BonusForSpy=0
BonusForEnemySpy=0
BonusSearchArts=5
BonusDamagePVPForAtackers=0
BonusDamagePVPForDefenders=0
BonusDamagePVMForAtackers=0
BonusDamagePVMForDefenders=0
BonusRangeForAtackers=0
BonusRangeForDefenders=0
Recruit-Novice=0
Recruit-Skilled=0
Recruit-Veteran=0
Recruit-Master=0
LimitRecruit-Novice=0
LimitRecruit-Skilled=0
LimitRecruit-Veteran=0
LimitRecruit-Master=0
Comands=0
LimitComands=0
BootyParts=0
BootyCash=0
BonusForCostCPSpy=0
BonusForCostCPAdvisor=0
Ideology=Stalkers
IdeologyBonus=1

Скопируйте этот текст в свой новый файл Leader-Medved.ini и внесите следующие изменения:

[main]
Img=gfx\icons\leaders\Medved.png
BonusForSpy=10
BonusForEnemySpy=-5
BonusSearchArts=5
BonusDamagePVPForAtackers=0
BonusDamagePVPForDefenders=0
BonusDamagePVMForAtackers=0
BonusDamagePVMForDefenders=0
BonusRangeForAtackers=0
BonusRangeForDefenders=0
Recruit-Novice=0
Recruit-Skilled=0
Recruit-Veteran=0
Recruit-Master=0
LimitRecruit-Novice=0
LimitRecruit-Skilled=0
LimitRecruit-Veteran=0
LimitRecruit-Master=0
Comands=0
LimitComands=0
BootyParts=0
BootyCash=0
BonusForCostCPSpy=0
BonusForCostCPAdvisor=0
Ideology=Stalkers
IdeologyBonus=3
📌 Что мы изменили по сравнению с прототипом
  • Img=gfx\icons\leaders\Medved.png — путь к нашему портрету
  • BonusForSpy=10 — +10% к успеху своих разведчиков (было 0)
  • BonusForEnemySpy=-5 — −5% к успеху вражеских разведчиков (было 0)
  • IdeologyBonus=3 — продвижение идеологии Сталкерство на 3% каждый ход (было 1%)
💡 Секция [main] с маленькой буквы
В реальных конфигах лидеров секция называется [main] (с маленькой буквы). Это работает благодаря регистронезависимости движка.

Шаг 2. Создайте портрет лидера

Поместите файл Medved.png (или .gif) по пути gfx\icons\leaders\Medved.png в папке вашего сценария (или в общей папке data\gfx\ игры).

💡 Если своего портрета пока нет
Можно временно скопировать портрет от существующего лидера. Например, скопируйте data\gfx\icons\leaders\Stalkers-COP.gif и переименуйте в Medved.png. Это позволит проверить работу лидера в игре до того, как нарисуете свой.

Шаг 3. Привяжите лидера к группировке в Main.ini

Откройте Main.ini вашего сценария и найдите секцию [Group-Leaders]. Добавьте строку с привязкой нового лидера к группировке:

[Group-Leaders]
Mutants=Leader-0
Stalkers=Leader-Medved    ; ← добавили нашего нового лидера
; ... остальные строки ...
📌 Формат привязки
Формат: Группировка=ТехНазвание_лидера. В нашем примере: Stalkers=Leader-Medved.
⚠️ Только один лидер на группировку
В секции [Group-Leaders] для каждой группировки может быть указан только один лидер. Если вы напишете две строки для одной группировки, игра использует последнюю.

Шаг 4. Добавьте локализацию

Откройте messages.csv вашего сценария и добавьте одну строку:

[Leaders.Leader-Medved].Name;Медведь
⚠️ У лидеров только .Name, без .Desc
В отличие от построек и улучшений, у лидеров нет поля описания. Только имя. Если добавить [Leaders.Leader-Medved].Desc;... — движок её проигнорирует.
⚠️ Формат ключа
Ключ в messages.csv должен совпадать с именем файла лидера без расширения. У нас файл называется Leader-Medved.ini, значит ключ — [Leaders.Leader-Medved].Name.

Регистр значения не имеет ([Leaders.Leader-Medved] и [Leaders.leader-medved] работают одинаково), но рекомендуется писать так же, как имя файла — это упрощает поиск по файлу messages.csv.

Разделитель между ключом и текстом — точка с запятой ;. Внутри самого текста символ ; использовать нельзя — строка оборвётся.

Шаг 5. Сохраните все файлы в правильной кодировке

  • leaders/Leader-Medved.ini — UTF-8 с BOM
  • Main.ini — UTF-8 с BOM
  • messages.csv — UTF-8 с BOM

Подробнее про кодировку: «Кодировка файлов».

✅ Проверка результата

  1. Запустите игру и начните свой сценарий
  2. Выберите группировку Одиночки и откройте информацию о лидере
  3. Убедитесь, что отображается новый лидер «Медведь» с корректным именем и портретом
  4. Проверьте, что отображаются правильные бонусы (+10% своей разведке, −5% вражеской)
  5. Подождите несколько ходов — убедитесь, что идеология «Сталкерство» продвигается примерно на 3% за ход
  6. Отправьте разведчика — проверьте, что шанс успеха действительно выше, чем был без лидера

⚠️ Вероятные ошибки

Лидер не отображается в игре
  • Проверьте, что файл Leader-Medved.ini лежит в папке leaders/ вашего сценария
  • Убедитесь, что в Main.ini → [Group-Leaders] добавлена строка Stalkers=Leader-Medved
  • Проверьте, что все файлы сохранены в UTF-8 с BOM
Вместо имени отображается техническое «Leader-Medved»

Это значит, что игра не нашла локализацию. Проверьте:

  • Ключ в messages.csv точно [Leaders.Leader-Medved].Name
  • Разделитель — точка с запятой ;
  • В тексте нет символа ;
  • messages.csv сохранён в UTF-8 с BOM
💡 Нюанс: лидер vs заместитель

Набор бонусных параметров у лидера и заместителя почти идентичен. Единственное отличие — у заместителя есть параметр Fraction (привязка к фракции внутри конфига), а у лидера привязка задаётся через Main.ini → [Group-Leaders].

Подробнее: справка Leaders, справка Advisors.

💡 Нюанс: смена лидера через события

Если вы хотите, чтобы лидер менялся в процессе игры (например, по сюжету), используйте тип события ChangeLeader в Events_Story.ini или RandomEvents с параметром NewLeader=Leader-Medved.

Подробнее: Events_Story.ini, RandomEvents.

🔗 Связанные разделы справки

  • Leaders — полное описание всех параметров лидеров
  • Advisors.ini — сравнение лидера и заместителя
  • Main.ini → [Group-Leaders] — привязка лидера к группировке
  • messages.csv — формат локализации
  • Events_Story.ini — тип события ChangeLeader
  • RandomEvents — тип события ChangeLeader
  • Матрица бонусов — как бонусы лидера складываются с другими источниками
  • Кодировка файлов — UTF-8 с BOM
