📚 Приветственное окно после запуска сценария (Tutorial.ini)

Файл Tutorial.ini описывает многостраничное окно обучения, которое показывается игроку после старта сценария. В игре его можно увидеть в самом обучении и в сценарии «Обрыв связи».

📋 Локализация (размещать в messages.csv)
[Tutorial.<название_страницы>].Text   - отображаемый текст страницы

Где <название_страницы> — это имя секции в квадратных скобках (например, Page-1, Page-2).

Как включить окно обучения

Чтобы окно обучения открывалось автоматически после старта сценария, в Settings.ini установите параметр:

[Main]
isTutorial=True

По умолчанию False — окно не открывается.

Секция [Main] — основные параметры

ПараметрТипОписание
CountPages@@ЦЕЛОЕ >0 Число страниц в обучении. Должно совпадать с реальным количеством секций [Page-X]. Лимита сверху нет
Face@@ПУТЬ Путь к портрету персонажа в окне обучения (по умолчанию для всех страниц). Можно переопределить на каждой странице отдельно
Img@@ПУТЬ Путь к изображению на странице (по умолчанию для всех страниц). Если пусто или параметр отсутствует — изображения не будет. Можно переопределить на каждой странице отдельно

Секции [Page-X] — страницы обучения

По одной секции на каждую страницу. X — порядковый номер страницы (начинается с 1, без пропусков).

ПараметрТипОписание
Face@@ПУТЬ Опционально. Переопределяет портрет персонажа для этой страницы. Если не указан — используется Face из [Main]
Img@@ПУТЬ Опционально. Переопределяет изображение для этой страницы. Если не указан — используется Img из [Main]. Если нужен пустой фон на конкретной странице — укажите Img= (пусто)
⚠️ Текст страницы — только через локализацию
Сам текст страницы не указывается в Tutorial.ini. Его нужно прописать в messages.csv ключом [Tutorial.Page-X].Text. Без локализации страница будет пустой.

Пример полного файла Tutorial.ini

; Файл: Tutorial.ini
[Main]
CountPages=3
Face=gfx\tutorial\default_face.png
Img=gfx\tutorial\default_background.png

[Page-1]
; Используем стандартный Face и Img из [Main]
; Текст: [Tutorial.Page-1].Text в messages.csv

[Page-2]
; Переопределяем портрет (другой персонаж говорит)
Face=gfx\tutorial\scientist_face.png
Img=gfx\tutorial\psy_installation.png

[Page-3]
; Переопределяем оба параметра
Face=gfx\tutorial\commander_face.png
Img=gfx\tutorial\final_screen.png

Соответствующие строки в messages.csv:

[Tutorial.Page-1].Text;Добро пожаловать в сценарий! В этом обучении вы узнаете основные механики игры.
[Tutorial.Page-2].Text;Пси-излучатель — мощное оружие. Его можно включать и выключать через панель управления.
[Tutorial.Page-3].Text;Удачи, сталкер! Зона ждёт своих героев.

Как создать своё окно обучения — чек-лист

  1. Создайте файл Tutorial.ini в папке вашего сценария
  2. В секции [Main] укажите CountPages (число страниц) и базовые Face и Img
  3. Добавьте секции [Page-1], [Page-2], … — по числу страниц. Переопределяйте Face/Img там, где нужно
  4. В messages.csv добавьте строки [Tutorial.Page-1].Text, [Tutorial.Page-2].Text и т.д.
  5. В Settings.ini установите isTutorial=True
  6. Подготовьте графику: портреты персонажей и фоновые изображения страниц
💡 Практические советы
  • 3–5 страниц — оптимальное количество. Больше — игрок устанет читать
  • Короткий текст — 2–3 предложения на страницу. Длинные простыни никто не читает
  • Разные персонажи — смена портрета между страницами делает обучение живым, как диалог нескольких персонажей
  • Изображения — скриншоты интерфейса или схем помогают понять механику быстрее, чем текст
🔗 Связанные разделы
  • Settings.ini — параметр isTutorial (включает показ окна после старта)
  • messages.csv — ключи [Tutorial.Page-X].Text
  • Кодировка файлов — UTF-8 с BOM (иначе кириллица будет кракозябрами)
