🗺 Файлы карты — обзор

Карта сценария состоит из набора взаимосвязанных файлов, которые вместе описывают географию игрового мира: изображение карты, территории, связи между ними, расположение иконок и дополнительную информацию.

💡 Используйте встроенный редактор карт!
Большинство файлов карты не нужно заполнять вручную. В игре есть встроенный редактор карт, который сам создаёт все необходимые файлы с правильной структурой. Редактировать вручную имеет смысл только settings.ini и локализацию в messages.csv.

Сводная таблица файлов карты

ФайлНазначениеКак создаётся
map.bmp / map.png / map.jpg Графическое изображение карты В любом графическом редакторе
map.bt Технический файл — как движок выделяет территории Только встроенный редактор
settings.ini Формат карты и локализация Вручную
Links.ini Связи между территориями (кто с кем граничит) Встроенный редактор
Territories.ini Статичные параметры территорий (артефакты, рекруты) Встроенный редактор
Territories_Icon_Coordinates.ini Координаты иконок группировок на территориях Встроенный редактор
TerritoriesInfo.ini К какой локации относится территория, изображение в меню Встроенный редактор
Locations/ Папка с конфигами локаций (заготовка на будущее) Вручную
📁 Где должны лежать файлы карты для мода?
Все файлы карты хранить в папке map/ внутри папки сценария (например, data\campaigns\scs\1story\map\).

⚙ Конфигурационный файл карты (settings.ini)

Небольшой файл с общими настройками карты. Находится в папке map/ сценария.

⚠️ Не путать с Settings.ini сценария!
Это разные файлы:
  • map/settings.ini — настройки карты (этот файл)
  • Settings.ini в корне сценария — настройки самого сценария (см. Settings.ini)

Параметры

ПараметрТипОписание
MapFormat @@ВЫБОР Формат файла изображения карты. Возможные значения: bmp, png, jpg
DefaultLocale @@ВЫБОР Какая локализация текста карты является изначальной. Значения: ruRU, enUS

Пример файла

; Файл: map\settings.ini
[Main]
MapFormat=bmp
DefaultLocale=ruRU
🖼 Форматы изображения карты
  • bmp — лучший формат. Движок грузит его быстрее остальных
  • png — грузится дольше, но несущественно. Поддерживает сжатие без потери качества
  • jpg — карта весит меньше всего, но грузится существенно дольше
Рекомендация: используйте bmp для малых и средних карт.

🔗 Файл связей между территориями (Links.ini)

Файл Links.ini описывает, какая территория с какой граничит. Движок использует эту информацию для:

  • Определения возможности атаки/передислокации между территориями
  • Расчёта маршрутов для ботов
  • Определения, является ли территория анклавом (изолированной)
💡 Создаётся редактором
Файл не нужно заполнять вручную. Используйте встроенный в игру редактор карт — он автоматически создаст Links.ini на основе того, как вы нарисуете границы территорий на карте.
⚠️ Ручное редактирование не рекомендуется
При ручном редактировании легко нарушить связи, что приведёт к багам: территории могут стать «отрезанными» от остальной карты, либо наоборот — появятся проходы там, где их быть не должно.

📍 Статичные параметры территорий (Territories.ini)

Файл Territories.ini описывает статичные параметры каждой территории: какие артефакты могут здесь появляться, сколько рекрутов генерируется и т.д. Эти параметры не меняются в процессе игры (в отличие от динамических в Main.ini → [ZonaX]).

💡 Создаётся редактором
Файл не нужно заполнять вручную. Используйте встроенный в игру редактор карт — он автоматически создаст Territories.ini с правильной структурой.
📌 Territories.ini vs Main.ini [ZonaX]
  • Territories.ini (файл карты) — статичные параметры, общие для всех игр на этой карте
  • Main.ini → [ZonaX] — динамичное состояние на старте конкретного сценария (владелец, гарнизон, постройки, активность мутантов)
Индексы территорий в обоих файлах совпадают.
🔗 Тип местности
Каждая территория имеет тип местности, который задаёт её характеристики (бонусы, вместимость построек). См. TypeLands.

🗺 Папка с конфигами локаций (Locations/)

Папка Locations/ содержит по одному ini-файлу на каждую локацию карты (группу территорий). Это заготовка на будущее — сейчас используется не полностью.

Формат файла локации

В каждом файле локации достаточно указать пустую секцию [Main]:

; Файл: Locations\Cordon.ini
[Main]
⚠️ Локализация обязательна
Даже если сам конфиг локации пустой, строки локализации делать обязательно. Без них название локации не будет отображаться в игре.

Локализация (размещать в messages.csv)

[Locations.<техническое название>].Name   - название локации
💡 Где размещать локализацию локаций
Обычно мододелы используют файл сценария (messages.csv в папке сценария), а не отдельный файл карты.
🔗 Связь с TerritoriesInfo.ini
Принадлежность территории к локации задаётся в TerritoriesInfo.ini.

📐 Координаты иконок территорий (Territories_Icon_Coordinates.ini)

Файл Territories_Icon_Coordinates.ini описывает, где именно на карте отображать иконку группировки-владельца территории (логотип из параметра IconMap в Groups).

💡 Создаётся редактором
Файл не нужно заполнять вручную. Используйте встроенный в игру редактор карт — при размещении территории на карте редактор автоматически сохраняет её координаты.
📌 Формат координат
Координаты задаются в пикселях относительно левого верхнего угла изображения карты. Ось X — горизонталь, Y — вертикаль.

ℹ Дополнительная информация о территориях (TerritoriesInfo.ini)

Файл TerritoriesInfo.ini содержит дополнительную информацию о каждой территории:

  • К какой локации относится территория (связь с Locations/)
  • Какое изображение отображается в меню территории
💡 Создаётся редактором
Файл не нужно заполнять вручную. Используйте встроенный в игру редактор карт — он автоматически создаст TerritoriesInfo.ini с правильной структурой.

🔧 Технический файл карты (map.bt)

Файл map.bt — служебный бинарный файл, который говорит движку, как выделять территории на карте при наведении курсора и клике.

☠ НЕ редактировать вручную!
Файл создаётся только через встроенный в игру редактор карт. Любое ручное редактирование приведёт к повреждению карты и ошибкам игры. См. «Рудименты и не трогать».
📌 Как создаётся
При сохранении карты в редакторе движок автоматически анализирует изображение и границы территорий, создавая map.bt с информацией о «кликабельных» областях каждой территории.

🖼 Изображение карты (map.bmp / map.png / map.jpg)

Основной графический файл карты — то, что игрок видит на экране во время игры. Может быть в форматах bmp, png или jpg.

🏆 Рекомендации по формату
ФорматСкорость загрузкиРазмер файлаКогда использовать
bmp 🟢 Быстрее всех 🔴 Больше всех Рекомендуется для малых и средних карт
png 🟡 Чуть дольше bmp 🟡 Средний Если нужно сжатие без потерь
jpg 🔴 Существенно дольше 🟢 Меньше всех Только если критичен размер мода
💡 Как связать изображение и файл настроек
В map/settings.ini параметр MapFormat должен точно соответствовать расширению вашего файла изображения:
  • Если файл map.bmp → MapFormat=bmp
  • Если файл map.png → MapFormat=png
  • Если файл map.jpg → MapFormat=jpg

Как создать свою карту — чек-лист

  1. Нарисуйте изображение карты в графическом редакторе (сохраните как map.bmp, map.png или map.jpg)
  2. Создайте папку map/ в папке вашего сценария
  3. Положите изображение в папку map/
  4. Запустите игру и откройте встроенный редактор карт
  5. Загрузите ваше изображение в редакторе
  6. Нарисуйте границы территорий — редактор автоматически создаст: map.bt, Links.ini, Territories.ini, Territories_Icon_Coordinates.ini, TerritoriesInfo.ini
  7. Сохраните карту в редакторе
  8. Создайте map/settings.ini с параметрами MapFormat и DefaultLocale
  9. Создайте папку Locations/ с конфигами локаций (по одному файлу на локацию, достаточно пустой секции [Main])
  10. Добавьте локализацию локаций в messages.csv: [Locations.<тех.название>].Name
  11. Настройте типы местности через TypeLands
  12. Пропишите владельцев и гарнизоны территорий в Main.ini → [ZonaX]
💡 Совет: начните с маленькой карты
Перед созданием большой карты (сотни территорий) попробуйте сделать маленькую — 10–15 территорий на одной локации. Так вы наступите на все типовые грабли и поймёте механику работы редактора, прежде чем браться за серьёзный проект. См. «С чего начать мододелу?» — 6-й уровень сложности модов.
