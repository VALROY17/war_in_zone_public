🏛 Идеологии (ideologies)

Папка ideologies\ в сценарии состоит из ini-файлов, каждый из которых представляет одну идеологию. Название файла — техническое название идеологии, которое используется в других конфигах. Каждый файл содержит один блок [Main].

⚠️ Самая «дорогая» сущность при добавлении
Добавление идеологии обязывает прописать её во всех группировках, где она может стать основной: секция [Название_идеологии] в каждом файле Groups, строки [Groups.*.идеология] в messages.csv, озвучка и графика.

Локализация (размещать в messages.csv)

[Ideologies.<техническое название>].Name   - название, отображаемое в игре

Как работает идеология в игре

МеханикаГде настраивается
Стартовая идеология группировкиMain.ini → [Group-Ideology]
Процентное распределение идеологий в группировке (сумма = 100)Main.ini → [Group-Ideology-Percent]
Продвижение идеологии каждым ходомIdeology + IdeologyBonus у заместителя и лидера
Принудительная смена идеологииEvents_Story.ini → тип ChangeIdeology; RandomEvents → тип ChangeIdeology
Добавить % идеологииТип события ChangeIdeologyPercent (⚠️ CountParam только положительный — см. «не трогать»)
Уход бойцов из-за идеологических разногласийSettings.ini → IdeologyLeaveUnitsNumEvent + SpecialEvents
Стоимость смены идеологии в КРUpgrades → тип IdeologyChangeBonus
Секция идеологии в конфиге группировкиGroups → [Название_идеологии]
Ачивка за принятие идеологииAchievements.ini → Type=IdeologyOnly, TargetIdeology

Как добавить новую идеологию — чек-лист

  1. Создайте ini-файл в папке ideologies\ сценария. Имя файла = техническое название идеологии
  2. Заполните блок [Main] с параметрами бонусов
  3. Добавьте строку локализации в messages.csv
  4. Для каждой группировки, где эта идеология может стать основной:
    • Добавьте секцию [Название_идеологии] в файл Groups
    • Добавьте строки локализации [Groups.<группировка>.<идеология>].Name и Description в messages.csv
    • Пропишите процент в Main.ini → [Group-Ideology-Percent]
  5. Создайте изображение идеологии (иконку)
  6. Если нужно — добавьте озвучку дипломатических фраз
🏷 Идеологии стандартного сценария
Из примера [Group-Ideology] в Main.ini: Stalkers, Crime, Control, AntiZone, Anarchy, Sectarianism, Mercenary, Exploring, Stability, Growth, Zombie.
