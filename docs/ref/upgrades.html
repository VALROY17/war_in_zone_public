⬆ Улучшения (upgrades)

Папка upgrades\ в сценарии состоит из ini-файлов, каждый из которых представляет одно улучшение. Название файла — техническое название улучшения, которое используется в других конфигах. Каждый файл содержит один блок [Main].

📊 Как работают улучшения
Улучшения дают глобальные бонусы группировке после их изучения. Тип эффекта захардкожен в движке, но коэффициент Bonus можно менять. Создать улучшение с новым типом эффекта нельзя — только использовать один из 15 доступных типов.

Локализация (размещать в messages.csv)

[Upgrades.<техническое название>].Name   - название, отображаемое в игре
[Upgrades.<техническое название>].Desc   - описание улучшения

Параметры

ПараметрТипОписание
Type@@ВЫБОРТип улучшения (один из 15, см. таблицу ниже). Захардкожен — определяет, какой эффект даёт улучшение
SortOrder@@ЦЕЛОЕПорядок отображения в окне улучшений. Чем меньше значение, тем раньше иконка в списке
Cost_Comands@@ЦЕЛОЕСтоимость изучения в командных ресурсах (КР)
Cost_Money@@ЦЕЛОЕСтоимость изучения в деньгах
Bonus@@ЦЕЛОЕКоэффициент бонуса. Может быть положительным или отрицательным. Интерпретация зависит от типа улучшения
Need@@НАЗВАНИЕТехническое название другого улучшения (имя файла без .ini), которое должно быть изучено перед этим
Logo-NonActive@@ПУТЬПуть к иконке улучшения (основное изображение)
⚠️ Рудименты: Logo-Active, Logo-Purchased, Logo-PurchasedActive
Эти три параметра не нужно указывать в конфиге — движок автоматически подставит пути к изображениям на основе Logo-NonActive и технического названия улучшения.

15 типов улучшений

Типы улучшений захардкожены в движке. Создать новый тип нельзя.

ТипЭффектПример значения Bonus
UpRecruitsCountCommingУвеличивает ежедневный прирост рекрутов каждого рангаBonus=1 — +1 рекрут каждого ранга в день
UpChanceSearchArtsCountУвеличивает шанс поиска артефактовBonus=10 — +10% к шансу поиска
UpCRCountCommingУвеличивает ежедневный прирост командных ресурсовBonus=4 — +4 КР в день
UpPartCountAfterKillMutantУвеличивает трофейные части мутантов после бояBonus=1 — +1 часть мутанта к базовому дропу
UpCashCountAfterKillStalkerУвеличивает трофейные деньги после боя со сталкерамиBonus=1 — +1 к деньгам к базовому дропу
UpChanceCountForReconnaissanceУвеличивает шанс успеха разведчиковBonus=10 — +10% к шансу успеха разведки
DownCountCRForKillMutantsУменьшает стоимость зачистки мутантов в КРBonus=2 — −2 КР к стоимости зачистки
DownCountCRForMoveAndBattleУменьшает стоимость передислокации и атак в КРBonus=1 — −1 КР к стоимости действий
DownCountCRForReconnaissanceУменьшает стоимость отправки разведчиков в КРBonus=2 — делит стоимость на 2 (или уменьшает на 50%)
UpRecruitsCountLimitУвеличивает максимальный лимит рекрутов каждого рангаBonus=1 — +1 к лимиту каждого ранга
UpCRCountLimitУвеличивает максимальный лимит командных ресурсовBonus=15 — +15 к лимиту КР
ImprovementProductivityWorkshopУвеличивает продуктивность мастерскихBonus=2 — +2 к производительности мастерских
IdeologyChangeBonusИзменяет стоимость смены идеологии в КРBonus=-7 — −7 КР к стоимости смены идеологии
RearmBonusИзменяет стоимость перевооружения в КРBonus=-11 — −11 КР к стоимости перевооружения
NoneНе даёт никакого эффекта. Используется как «заглушка» для создания веток дерева технологийBonus=0

Дерево технологий (параметр Need)

Параметр Need создаёт зависимости между улучшениями. Если указано Need=Upgrade-1, то улучшение Upgrade-2 нельзя изучить, пока не изучено Upgrade-1.

💡 Пример дерева технологий
; Upgrade-1.ini — базовое улучшение (без требований)
[Main]
Type=UpRecruitsCountLimit
SortOrder=10
Cost_Comands=5
Cost_Money=1000
Bonus=1
Logo-NonActive=gfx\icons\technologies\1.png

; Upgrade-2.ini — требует Upgrade-1
[Main]
Type=UpRecruitsCountComming
SortOrder=20
Cost_Comands=8
Cost_Money=1500
Bonus=1
Need=Upgrade-1
Logo-NonActive=gfx\icons\technologies\2.png

; Upgrade-3.ini — требует Upgrade-2
[Main]
Type=UpRecruitsCountLimit
SortOrder=30
Cost_Comands=10
Cost_Money=2000
Bonus=2
Need=Upgrade-2
Logo-NonActive=gfx\icons\technologies\3.png
📌 Блокировка улучшений
Улучшения можно полностью заблокировать в сценарии через параметр ExcludedUpgrades в Settings.ini. Если заблокированное улучшение указать в AI.ini, игра выдаст ошибку на ходе бота.

Как добавить новое улучшение — чек-лист

  1. Создайте ini-файл в папке upgrades\ сценария. Имя файла = техническое название улучшения
  2. Заполните блок [Main] с параметрами (Type, SortOrder, Cost_Comands, Cost_Money, Bonus)
  3. Если нужно — укажите Need для создания зависимости
  4. Укажите Logo-NonActive — путь к иконке
  5. Создайте 1 файл изображений с правильным именем:
    • <имя>.png — основная иконка
  6. Добавьте локализацию в messages.csv
💡 Пример полного файла улучшения
; Файл: upgrades\Upgrade-MyMod-1.ini
[Main]
Type=UpChanceSearchArtsCount
SortOrder=500
Cost_Comands=20
Cost_Money=10000
Bonus=15
Need=Upgrade-10
Logo-NonActive=gfx\icons\technologies\mymod_1.png
Не забудьте создать 1 файл изображения: mymod_1.png.
🔗 Где ещё используется
  • Main.ini — [Group-Upgrades] (улучшения, купленные со старта)
  • AI.ini — какие улучшения бот будет покупать
  • Settings.ini — ExcludedUpgrades (блокировка улучшений)
  • Events_Story.ini — тип ChangeStatusUpgrade, параметр TargetUpgradeIndex
  • RandomEvents — тип ChangeStatusUpgrade, параметр TargetUpgradeIndex
  • messages.csv — ключи [Upgrades.*]
