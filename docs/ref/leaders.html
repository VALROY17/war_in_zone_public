👑 Лидеры (leaders)

Папка leaders\ в сценарии состоит из ini-файлов, каждый из которых представляет одного лидера. Название файла — техническое название лидера, которое используется в других конфигах. Каждый файл содержит один блок [Main].

📊 Бонусы этого конфига
Все бонусы лидера — глобальные, действуют на всю группировку. См. Матрицу бонусов.

Локализация (размещать в messages.csv)

[Leaders.<техническое название>].Name   - название, отображаемое в игре

Параметры

⚠️ Отрицательные значения
Многие параметры принимают отрицательные числа. Отрицательное значение = штраф вместо бонуса.

🖼 Оформление

ПараметрТипОписание
Img@@ПУТЬПуть к изображению лидера для интерфейса

🎖 Разведка и артефакты

ПараметрТипОписание
BonusForSpy@@ЦЕЛОЕМодификатор шанса успеха своих разведчиков в %. Положительное значение = помощь, отрицательное = помеха
BonusForEnemySpy@@ЦЕЛОЕМодификатор шанса успеха вражеских разведчиков в %. Положительное значение = помощь врагу, отрицательное = помеха врагу
BonusSearchArts@@ЦЕЛОЕМодификатор к поиску артефактов в %. Положительное значение = больше находок, отрицательное = меньше

⚔ Боевые бонусы

ПараметрТипОписание
BonusDamagePVPForAtackers@@ЦЕЛОЕМодификатор урона нападающим в PvP-боях %
BonusDamagePVPForDefenders@@ЦЕЛОЕМодификатор урона обороняющимся в PvP-боях %
BonusDamagePVMForAtackers@@ЦЕЛОЕМодификатор урона нападающим в PvM-боях (против мутантов) %
BonusDamagePVMForDefenders@@ЦЕЛОЕМодификатор урона обороняющимся в PvM-боях %
BonusRangeForAtackers@@ЦЕЛОЕМодификатор дальности атаки нападающим %
BonusRangeForDefenders@@ЦЕЛОЕМодификатор дальности атаки обороняющимся %

💰 Экономика

ПараметрТипОписание
BootyParts@@ЦЕЛОЕАбсолютная прибавка к трофейным частям мутантов после боя. Например, BootyParts=5 даёт ровно +5 частей к базовому дропу
BootyCash@@ЦЕЛОЕАбсолютная прибавка к трофейным деньгам после боя. Например, BootyCash=100 даёт ровно +100 к деньгам к базовому дропу
BonusForCostCPSpy@@ЦЕЛОЕМодификатор стоимости отправки разведчиков в КР. Положительное значение = дороже, отрицательное = дешевле
BonusForCostCPAdvisor@@ЦЕЛОЕМодификатор стоимости назначения заместителя в КР. Положительное значение = дороже, отрицательное = дешевле
BonusForCostCPMainBase@@ЦЕЛОЕМодификатор стоимости смены главной базы в КР
BonusPercentLostResources@@ЦЕЛОЕМодификатор % потери ресурсов при потере главной базы

🏛 Идеология

ПараметрТипОписание
Ideology@@НАЗВАНИЕТехническое наименование идеологии, которую продвигает лидер (например, Stalkers, Crime, AntiZone)
IdeologyBonus@@ЦЕЛОЕЕжеходный прирост в процентных пунктах указанной идеологии. Например, IdeologyBonus=5 даёт ровно +5% к доле этой идеологии в группировке каждый ход. Очень большие значения быстро вытесняют все остальные идеологии

Сравнение «бонусной цепочки»

Лидер, заместитель, идеология и внутреннее правило дают почти один и тот же набор бонусов. Основные различия:

Параметр👥 Advisors👑 Leaders🏛 Ideologies📜 Rules
Бонусный блок (25 параметров)✅✅✅✅
Img✅✅✅Img-Available
Ideology / IdeologyBonus✅✅——
Fraction✅———
CanUseRule-Rule-1…5——✅—
💡 Advisors vs Leaders
Набор параметров у лидера и заместителя почти идентичен. Единственное отличие — у заместителя есть параметр Fraction (привязка к фракции внутри конфига), у лидера привязка к фракции задаётся через Main.ini в секции [Group-Leaders].

Как добавить нового лидера — чек-лист

  1. Создайте ini-файл в папке leaders\ сценария. Имя файла = техническое название лидера
  2. Заполните блок [Main] с параметрами бонусов
  3. Добавьте строку локализации в messages.csv
  4. Привяжите лидера к группировке в Main.ini → [Group-Leaders] (формат: Группировка=ТехНазвание_лидера)
  5. Создайте изображение лидера (портрет)

🔗 Где ещё используется
  • Main.ini — [Group-Leaders] (привязка лидера к группировке, формат: Группировка=ТехНазвание_лидера)
  • Events_Story.ini — тип события ChangeLeader, параметр NewLeader
  • RandomEvents — тип события ChangeLeader, параметр NewLeader
  • messages.csv — ключи локализации [Leaders.*]
