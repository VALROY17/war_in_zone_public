🌐 Файл локализации (messages.csv)

Файл messages.csv содержит все тексты, отображаемые в игре: названия сценариев, группировок, лидеров, заместителей, товаров, событий и многое другое. Каждый конфиг, имеющий отображаемое в игре название или описание, берёт текст именно отсюда.

💡 Чем открывать
  • Для чтения — можно открывать через Excel (но осторожно с кодировкой)
  • Для редактирования — используйте Notepad++ или обычный Блокнот Windows. Excel может испортить кодировку при сохранении

Кодировка файла

⚠️ Только UTF-8 с BOM
Файл должен сохраняться строго в кодировке UTF-8 с BOM. Без BOM кириллица в игре будет отображаться «кракозябрами». Подробнее: Кодировка файлов.

Формат строк

Каждая строка файла имеет формат:

Ключ;Текст

Разделителем выступает точка с запятой ;.

⚠️ Символ ; запрещён внутри текста
Не используйте ; внутри самого текста, так как это разделитель между технической ссылкой и игровым текстом. Если в тексте нужна точка с запятой — перепишите предложение или используйте запятую.

Специальные символы и форматирование

СимволНазначениеПример
%sПростая подстановка значения (строка или число) Вы нашли %s рублей → «Вы нашли 500 еды»
%0:s, %1:s, … Подстановка значения по индексу (формат Delphi). %0:s — первый аргумент, %1:s — второй и т.д. Используется, когда нужно вставить несколько значений Сталкер %0:s на территории %1:s → «Сталкер Меченый на территории Кордон»
||Перенос следующей части текста на новую строку (красная строка) Первая строка.||Вторая строка.
💡 Разница между %s и %N:s
  • %s — простая подстановка, значения вставляются по порядку
  • %0:s, %1:s — подстановка по индексу, можно менять порядок и использовать одно значение несколько раз: %0:s атакует %1:s, а %1:s защищается
Используйте %N:s, когда в событии передаётся несколько аргументов.

Как добавить локализацию для нового элемента — чек-лист

  1. Определите тип элемента (товар, лидер, событие и т.д.)
  2. Откройте messages.csv в Notepad++ (или создайте его в папке сценария)
  3. Добавьте строки по формату Ключ;Текст
  4. Убедитесь, что ключ точно совпадает с техническим названием из конфига (регистр важен!)
  5. Сохраните файл в кодировке UTF-8 с BOM
  6. Проверьте, что в тексте нет символа ;

Типичные ошибки

ОшибкаПоследствияКак исправить
Файл сохранён без BOMКириллица отображается кракозябрами В Notepad++: Кодировки → Преобразовать в UTF-8-BOM
Символ ; внутри текста Строка разбивается на части, текст обрезается Замените ; на запятую или перепишите предложение
Опечатка в ключе Текст не отображается, вместо него показывается техническое название Сверьте ключ с техническим названием в конфиге (регистр важен!)
Забыли .Name или .Desc Игра не найдёт нужную строку Проверьте формат: [Тип.ТехНазвание].Поле
Использование кавычек " как в настоящем CSV Кавычки отображаются как часть текста Не оборачивайте текст в кавычки — формат не классический CSV
Комментарии через # или ; Строка считается обычной и ломает парсинг В messages.csv нет комментариев — удаляйте лишние строки

Механизм наследования

Как и с другими файлами, работает механизм наследования от data\default\:

  • Если в вашем сценарии нет messages.csv — игра использует дефолтный файл
  • Если есть — игра берёт строки из вашего файла, а недостающие — из дефолтного
  • Если ключ есть в обоих файлах — ваша версия перезаписывает дефолтную
💡 Перевод существующего сценария
Чтобы перевести существующий сценарий на другой язык:
  1. Скопируйте messages.csv из сценария
  2. Переведите только текстовую часть (после ;), не трогая ключи
  3. Сохраните как messages.csv в нужной кодировке
  4. В Settings.ini можно указать DefaultLocale=enUS для английской версии
