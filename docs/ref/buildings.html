🏗 Постройки (Buildings)

Папка Buildings\ в сценарии состоит из ini-файлов, каждый из которых представляет одну постройку. Название файла — техническое название постройки, которое используется в других файлах, например, в Main.ini сценария. Каждый файл содержит один блок [Main].

⚠️ Единственный конфиг со смешанной областью бонусов
У постройки лимиты рекрутов и КР — глобальные (🌍), а прирост, боевые, разведка, трофеи и экономика — только на своей территории (📍). Полная таблица — в Матрице бонусов. Глобальные бонусы действуют, пока группировка владеет территорией с постройкой.

Локализация (размещать в messages.csv)

[Buildings.<техническое название>].Name   - название, отображаемое в игре
[Buildings.<техническое название>].Desc   - описание постройки

Параметры

⚙ Основные

ПараметрТипОписание
CanBeDestroyed@@BOOLРазрешён ли снос постройки (True или False). По умолчанию True
Logo-NonActive@@ПУТЬПуть к изображению постройки (единственное изображение, отдельного "активного" состояния у построек нет)
Type@@ВЫБОРТип постройки. Возможные значения:
• None — обычная постройка (большинство зданий)
• Workshop — мастерская для модификации амуниции через рецепты
• Production — производит один ресурс из другого (или "из воздуха")

💰 Экономика — все 📍 территориальные

ПараметрТипОписание
BootyParts@@ЦЕЛОЕАбсолютная прибавка к трофейным частям мутантов после боя на этой территории (например, BootyParts=5 даёт ровно +5 частей)
BootyCash@@ЦЕЛОЕАбсолютная прибавка к трофейным деньгам после боя на этой территории (например, BootyCash=100 даёт ровно +100 к деньгам)
BonusForCostCPSpy@@ЦЕЛОЕМодификатор стоимости отправки разведчиков в КР
BonusForCostCPAdvisor@@ЦЕЛОЕМодификатор стоимости назначения заместителя в КР
BonusForCostCPMainBase@@ЦЕЛОЕМодификатор стоимости смены главной базы в КР
BonusPercentLostResources@@ЦЕЛОЕМодификатор % потери ресурсов при потере главной базы
⚠️ BootyParts и BootyCash у построек
В отличие от лидеров, заместителей и идеологий (у которых эти бонусы глобальные), у построек они работают только на территории, где стоит постройка. И это всегда абсолютное значение, а не множитель!

🏗 Стоимость постройки

ПараметрТипОписание
Custom-Resource@@НАЗВАНИЕТехническое название ресурса/товара, которое требуется для постройки. Если дополнительный ресурс не нужен — оставьте пустым
Cost-Custom@@ЦЕЛОЕКоличество ресурса из Custom-Resource, требуемое для постройки
Cost-Money@@ЦЕЛОЕСтоимость постройки в деньгах
Cost-Comands@@ЦЕЛОЕСтоимость постройки в КР

🔗 Требования для постройки

ПараметрТипОписание
Need-UpgradeIndex@@НАЗВАНИЕТехническое название улучшения, которое должно быть исследовано перед постройкой. Если требования нет — оставьте пустым
Need-Building@@НАЗВАНИЕТехническое название другой постройки, которая должна быть построена на этой территории перед текущей. Если требования нет — оставьте пустым

🏭 Производство (только для Type=Production)

ПараметрТипОписание
ProductionNameFrom@@НАЗВАНИЕТехническое название ресурса/товара, которое потребляет постройка. Если производит "из воздуха" — оставьте пустым
ProductionCountFrom@@ЦЕЛОЕСколько потребляет постройка. Укажите 0, если производит "из воздуха"
ProductionNameTo@@НАЗВАНИЕТехническое название ресурса/товара, которое производится
ProductionCountTo@@ЦЕЛОЕСколько производится за ход
💡 Пример: производство "из воздуха"
Если постройка производит ресурс без потребления другого (например, генерирует деньги из ничего):
ProductionNameFrom= (пусто)
ProductionCountFrom=0
ProductionNameTo=Money
ProductionCountTo=10
🔗 Где ещё используется
  • Main.ini — [ZonaX] Buildings-Count (список построек на территории)
  • TypeLands — CountBuildings (вместимость территории по постройкам)
  • AI.ini — MainBaseBuildings, BorderBuildings, MaxBuildingCount (стратегия ИИ по застройке)
  • Settings.ini — ExcludedBuildings, BasedCostDestroyBuildComands, BasedImprovementProductivityWorkshop
  • Receipts — RequiredBuildings (постройка-мастерская через рецепты изготавливает товары)
  • Events_Story.ini — типы событий CheckBuilding, Build, Destroy
  • RandomEvents — типы Build, Destroy
  • Upgrades — ImprovementProductivityWorkshop (улучшение продуктивности мастерских)
