🏆 Достижения (Achievements.ini)

Файл Achievements.ini находится в папке каждого сценария (например, data/campaigns/shoc/1story/Achievements.ini) и описывает достижения, которые игрок может получить в этом сценарии.

Локализация (размещать в messages.csv)

[Achievements.<Название>].Name        - название ачивки
[Achievements.<Название>].Desc        - полное описание для окна события
[Achievements.<Название>].Desc-Logo   - описание в окне выбора сценария

«Название» — это техническое название секции ачивки из [Achiv-X].

Параметры ачивки

ПараметрТипОписание
ID@@НАЗВАНИЕОбязательный. Уникальный идентификатор для сохранения. Должен отличаться от всех ID других ачивок во всех файлах Achievements.ini игры. Рекомендуемый формат: ID = modNameYourModX, где NameYourMod — название мода без пробелов, а X — двухзначный номер (например, 01, 02, 03)
Type@@ВЫБОРТип условия получения ачивки. Возможные значения: ZonaControl, KillFraction, Conquest, IdeologyOnly, EventFlag. См. таблицу ниже
DifficultyLevel@@ВЫБОРТребуемый уровень сложности. Значения: Any (любой), Novice (новичок), Skilled (опытный), Veteran (ветеран), Master (мастер)
Img@@ПУТЬПуть к изображению ачивки для окна события при её получении
ImgLogoEnabled@@ПУТЬПуть к изображению ачивки для окна выбора сценария (когда ачивка уже получена). Для неполученных ачивок движок автоматически делает это изображение чёрно-белым
SoundFX@@BOOLВоспроизводить ли звук при получении ачивки (True или False)
SoundFXWayFile@@ПУТЬПуть к звуковому файлу, который воспроизводится при получении ачивки
StartStep@@ЦЕЛОЕХод, с которого начинается проверка условия ачивки (включительно). Значение 0 означает «с самого начала игры»
LimitStep@@ЦЕЛОЕХод, до которого проверяется условие ачивки (включительно). Значение 0 означает «без ограничения по ходам»
NotWorkFractionCount@@ЦЕЛОЕКоличество фракций, которые не учитываются при проверке ачивки (обычно это нейтральные или неигровые фракции)
FractionX@@НАЗВАНИЕТехническое название фракции, которая игнорируется. X — порядковый номер от 1 до значения NotWorkFractionCount

Параметры для конкретных типов ачивок

Тип: ZonaControl (Контроль территорий)

ПараметрТипОписание
CountNeedZona@@ЦЕЛОЕКоличество территорий, которые нужно контролировать
Zona-X@@ЦЕЛОЕНомер территории, которую нужно контролировать. X — порядковый номер от 1 до значения CountNeedZona

Тип: KillFraction (Пережить уничтожение фракции)

ПараметрТипОписание
TargetKillFraction@@НАЗВАНИЕТехническое название фракции, уничтожение которой нужно пережить

Тип: Conquest (Захват всей Зоны)

Не требует дополнительных параметров. Ачивка выдаётся, когда игрок захватывает все территории на карте.

Тип: IdeologyOnly (Смена идеологии)

ПараметрТипОписание
TargetIdeology@@НАЗВАНИЕТехническое название идеологии, которую должна принять фракция игрока

Тип: EventFlag (Активация ивент-флага)

ПараметрТипОписание
TargetFlag@@НАЗВАНИЕТехническое наименование ивент-флага, который должен быть активирован в событии из Events_Story.ini. Движок отслеживает результат выполнения ивента по системе, схожей с ивент-флагами

Типы ачивок (сводная таблица)

ТипОписаниеДополнительные параметры
ZonaControlКонтролировать указанные территорииCountNeedZona, Zona-X
KillFractionПережить уничтожение указанной фракцииTargetKillFraction
ConquestЗахватить всю Зону—
IdeologyOnlyСменить идеологию группировки на указаннуюTargetIdeology
EventFlagАктивировать указанный ивент-флаг в событииTargetFlag
⚠️ Не забудьте включить ачивки в сценарии
Достижения работают только если в Settings.ini задано Achievements=True и параметр AchievementsCount совпадает с реальным числом ачивок в файле.
⚠️ Лимит ачивок
Максимальное число ачивок в одном сценарии = 16
💡 Пример полной секции ачивки
[Achiv-1]
ID=myMod01
Type=ZonaControl
DifficultyLevel=Any
Img=gfx\icons\achievements_SHOC\Taked.png
ImgLogoEnabled=gfx\icons\achievements_SHOC\unlock\1.png
SoundFX=True
SoundFXWayFile=sfx\achiv.wav
StartStep=0
LimitStep=0
CountNeedZona=3
Zona-1=85
Zona-2=108
Zona-3=191
NotWorkFractionCount=2
Fraction1=Mutants
Fraction2=Zombie
🔗 Где ещё используется
  • Settings.ini — параметры Achievements и AchievementsCount
  • Events_Story.ini — ивент-флаги для типа EventFlag
  • Difficulty.ini — уровни сложности для параметра DifficultyLevel
  • messages.csv — ключи локализации [Achievements.*]
