🔧 Основной файл настроек сценария (Settings.ini)

Файл Settings.ini находится в папке сценария и содержит статичные настройки, которые определяют правила игры: условия победы, стоимости действий, экономику, мутантов, пси-установки и многое другое. В отличие от Main.ini, который хранит динамичное состояние мира, этот файл задаёт неизменяемые параметры сценария.

Локализация (размещать в messages.csv)

ScenarioName;Название сценария
ScenarioDescription;Описание сценария
ScenarioVictoryDescription;Описание условий победы
ScenarioLoseDescription;Описание условий поражения

Эти ключи размещаются в файле messages.csv.

Секция [Main] — основные настройки

📋 Общие параметры

ПараметрТипОписание
isTutorial@@BOOLЕсли True, то после старта сценария сразу открывается окно обучения. По умолчанию False
Map@@НАЗВАНИЕНазвание папки с файлами глобальной карты (например, map_sac1). Папка должна находиться в data\default\Map\ или в папке сценария
DefaultLocale@@ВЫБОРЛокализация по умолчанию для сценария. Значения: ruRU (русский), enUS (английский). Мододел может добавить собственные локализации
GroupsForPlayer@@НАЗВАНИЯСписок группировок, за которые могут играть игроки. Перечислять технические названия через запятую (например, Stalkers,Bandits,Duty)
MedicName@@НАЗВАНИЕТехническое название ресурса из Goods, используемого вместо медикаментов. По умолчанию Medic
SuppliesName@@НАЗВАНИЕТехническое название ресурса из Goods, используемого вместо боеприпасов. По умолчанию Supplies
FoodName@@НАЗВАНИЕТехническое название ресурса из Goods, используемого вместо еды. По умолчанию Food
ScenarioLogo-Standart@@ПУТЬПуть к изображению логотипа сценария (отображается после выбора кампании)
ScenarioLogo-Active@@ПУТЬПуть к изображению логотипа сценария при наведении курсора мыши

🏁 Условия победы и поражения

ПараметрТипОписание
StandardWinCanChange@@BOOLМожет ли игрок изменять настройки стандартной победы перед стартом
StandardWinTypesDefault@@ВЫБОРТип дополнительной победы по умолчанию. Значения:
0 — выключено
1 — частичная победа (захватить более половины территорий)
2 — групповая победа (победить в составе альянса)
3 — частично-групповая победа
StandardWinPartyDisabled@@BOOLОтключить возможность победы союзным альянсом
End-Standart-Victory@@BOOLВключена ли стандартная победа по захвату всех территорий Зоны
End-Standart-Lose@@BOOLВключено ли стандартное поражение по потере всех территорий
End-Step-Victory@@BOOLВключена ли победа, если игрок доживёт до хода, указанного в EndStep
End-Step-Lose@@BOOLВключено ли поражение, если игрок достигнет хода, указанного в EndStep
End-EventFlag-Victory@@BOOLВключена ли победа по ивент-флагу (в Events_Story.ini использовать флаг EndVictory)

EndStep@@ЦЕЛОЕНомер хода, который считается финальным для End-Step-Victory и End-Step-Lose
MinimalControlToWin@@ЦЕЛОЕНадбавка сверх половины территорий для частичной победы. Например, если на карте 99 территорий, то значение 1 означает необходимость захвата 50 территорий (99÷2=49, 49+1=50)

Секция [Music]

Список файлов музыки, используемой в сценарии. Каждый файл указывается на отдельной строке:

[Music]
music\track1.ogg
music\track2.ogg
music\track3.ogg

Секция [AmbientSounds]

Список файлов фоновых звуков в сценарии. Каждый файл указывается на отдельной строке:

[AmbientSounds]
sfx\ambient\wind.ogg
sfx\ambient\birds.ogg
sfx\ambient\distant_explosion.ogg

  • Achievements.ini — достижения сценария
