💰 Настройки параметров торговцев (Traders.ini)

Файл Traders.ini описывает параметры торговцев сценария: стоимость связи, шанс успеха, временные окна доступности и множители цен по категориям товаров. Ассортимент (какие товары у кого продаются) задаётся отдельно в TraderGoods.ini.

📋 Локализация (размещать в messages.csv)
[Traders.<техническое название>].Name      - название торговца (например, «Сидорович»)
[Traders.<техническое название>].NeedText   - описание условий доступа к торговцу
                                              (например, «Требуется контроль Бара»)

Типы торговцев (секции доступности)

В игре есть 3 типа торговцев, каждый со своей секцией в файле:

СекцияОписание
[YourGroup]Торговец своей группировки (привязан к игроку). Параметр Need игнорируется — см. «Рудименты и не трогать»
[OtherGroup]Торговец другой группировки (привязан к конкретной фракции). Параметр Need игнорируется — см. «Рудименты и не трогать»
[World], [TraderX]Нейтральные торговцы типа Сидоровича, Бармена и т.д. X — порядковый номер (Trader1, Trader2, и т.д.). Число торговцев данного типа можно добавлять сколько потребуется (лимита нет)
⚠️ YourGroup и OtherGroup — параметр Need не работает
У торговцев группировок ([YourGroup] и [OtherGroup]) движок автоматически привязывает торговца к его группировке и игнорирует значение Need. Указывать его в этих секциях бессмысленно. Подробнее: «Рудименты и не трогать».

Параметры торговца

ПараметрТипОписание
Need@@ЦЕЛОЕ ≥0 Индекс территории, которой необходимо владеть для доступа к торговцу. 0 — торговец доступен при владении любой территорией. Работает только в секциях [World]/[TraderX]
Cost@@ЦЕЛОЕ Стоимость попытки установить связь с торговцем в КР. 0 — бесплатно
Chance@@ЦЕЛОЕ 1-100 Шанс успеха попытки установить связь в %. 100 — гарантированный успех, 50 — 50/50
StartStep@@ЦЕЛОЕ ≥0 Номер хода, с которого торговец становится доступен. 0 — доступен с самого начала игры
EndStep@@ЦЕЛОЕ ≥0 Номер хода, после которого торговец становится недоступен. 0 — торговец не отключается никогда
Coef-Sell-X@@ДРОБНОЕ Множитель цены продажи игроком товаров категории X. 1,0 = 100% цены, 0,5 = 50% цены (торговец даёт меньше денег). Задаётся отдельно для каждой категории
Coef-Buy-X@@ДРОБНОЕ Множитель цены покупки игроком товаров категории X. 1,0 = 100% цены, 1,5 = 150% цены (торговец продаёт дороже). Задаётся отдельно для каждой категории

Категории товаров

Множители Coef-Sell-X и Coef-Buy-X настраиваются по категориям товаров. Категория товара задаётся в его конфиге параметром Category (см. Goods).

🏷 9 стандартных категорий
  • Food — еда
  • Medic — медикаменты
  • Supplies — боеприпасы
  • Parts — части тел мутантов
  • Arts — артефакты
  • Weapon — оружие
  • Armor — броня
  • BuildingMaterials — строительные материалы
  • AmmoComponents — компоненты боеприпасов

Можно создавать свои категории — просто укажите новое имя в Category товара и добавьте соответствующий Coef-Sell-NewCategory в Traders.ini.

Как добавить нового торговца — чек-лист

  1. Откройте Traders.ini в папке вашего сценария (или скопируйте из data\default\)
  2. Добавьте секцию [TraderN] (где N — следующий свободный номер)
  3. Заполните параметры: Need, Cost, Chance, StartStep, EndStep
  4. Добавьте множители Coef-Sell-X и Coef-Buy-X для нужных категорий товаров
  5. Добавьте строки локализации в messages.csv: [Traders.TraderN].Name и [Traders.TraderN].NeedText
  6. Откройте TraderGoods.ini и укажите, какие товары продаёт этот торговец (TraderN=True в блоках товаров)

Как работает торговля — логика

Когда игрок пытается открыть магазин торговца, игра выполняет проверку:

  1. Доступен ли торговец по времени? — проверяется StartStep и EndStep
  2. Владеет ли игрок нужной территорией? — проверяется Need (для [World] и [TraderX])
  3. Достаточно ли КР? — списывается Cost
  4. Бросок на успех — случайное число от 1 до 100 сравнивается с Chance. При успехе магазин открывается, при неудаче — игрок теряет КР впустую
  5. Проверка дипломатии — для [OtherGroup] проверяется CanTradeIf* в Groups
💡 Совет по балансу множителей
  • Coef-Sell (игрок продаёт): чем меньше значение, тем невыгоднее продавать. Обычно 0,4–0,8
  • Coef-Buy (игрок покупает): чем больше значение, тем дороже покупка. Обычно 1,2–2,0
  • Разница между Sell и Buy создаёт прибыль торговца и дефицит игрока — это основа экономики
🔗 Где ещё используется
  • TraderGoods.ini — ассортимент торговцев (какие товары у кого)
  • Goods — параметр Category у товаров определяет, к какой категории относится товар
  • Groups → CanTradeIf* — доступность торговли с другими группировками
  • Рудименты — Need не работает в [YourGroup]/[OtherGroup]
  • messages.csv — ключи [Traders.*]
