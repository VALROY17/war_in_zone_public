🔧 Рецепты модифицирования через мастерскую (Receipts)

Папка Receipts\ в сценарии состоит из ini-файлов, каждый из которых представляет один рецепт для мастерской. Каждый файл содержит один блок [Main].

🔩 Как это работает
Рецепт описывает превращение: входные ресурсы → результат. Игрок тратит входные ресурсы в мастерской и получает результат. Это основной механизм прокачки амуниции.

Параметры

ПараметрТипОписание
Upgrade0-Resource@@НАЗВАНИЕТехническое название ресурса из Goods, которое требуется для улучшения (первый входной слот)
Upgrade0-Quantity@@ЦЕЛОЕСколько нужно ресурса для улучшения. Можно не указывать, по умолчанию 1
Upgrade1-Resource@@НАЗВАНИЕТехническое название второго ресурса (второй входной слот, опционален)
Upgrade1-Quantity@@ЦЕЛОЕСколько нужно второго ресурса. Можно не указывать, по умолчанию 1
Result-Resource@@НАЗВАНИЕТехническое название ресурса или предмета из Goods, в которое улучшается
Result-Quantity@@ЦЕЛОЕСколько получится ресурса после улучшения. Можно не указывать, по умолчанию 1
RequiredBuildings@@НАЗВАНИЯСписок построек из Buildings через запятую, необходимых для разблокировки рецепта
⚠️ Максимум 2 входных слота
Upgrade0-* и Upgrade1-* — это жёсткий лимит движка. Третьего входного ресурса в рецепте быть не может. См. Лимиты движка.

Структура рецепта

[Main]
; Вход — слот 0 (обязательный)
Upgrade0-Resource=PM
Upgrade0-Quantity=1

; Вход — слот 1 (опциональный, можно не указывать)
Upgrade1-Resource=Supplies
Upgrade1-Quantity=50

; Результат
Result-Resource=PM-Upgraded
Result-Quantity=1

; Какая постройка должна быть, чтобы рецепт открылся
RequiredBuildings=Workshop

⚠️ Имена PM, Parts, PM-Upgraded, Workshop в примере — условные. Подставьте свои технические названия из папок Goods/ и Buildings/.

💡 Пример реального рецепта
Вот как выглядит рецепт из дефолтного конфига (улучшение пистолета ПМ): 
[Main]
Upgrade0-Resource=PM
Upgrade0-Quantity=1
Upgrade1-Resource=Parts
Upgrade1-Quantity=3
Result-Resource=PM-Upgraded
Result-Quantity=1
RequiredBuildings=Workshop
Этот рецепт требует 1 пистолет ПМ и 3 части мутантов для получения улучшенного ПМ. Рецепт доступен только если на территории есть постройка Workshop.
💡 Локализация рецепта
У рецепта нет собственного ключа в messages.csv. Игра отображает названия которых берутся из [Goods.*].

Стоимость и продуктивность модификации

Цена модификации (в рамках мощности мастерских) считается не в рецепте, а в Settings.ini:

ПараметрТипЧто делает
BasedCostForUpgradeAmmo-Money@@ДРОБНОЕБазовый множитель цены на модификацию амуниции в деньгах (можно указывать дробные значения через запятую: 1,5)
BasedCostForUpgradeAmmo-Comands@@ЦЕЛОЕБазовая стоимость в КР на привлечение одной мастерской к модификации амуниции
BasedImprovementProductivityWorkshop@@ЦЕЛОЕБазовая продуктивность одной мастерской для модификации чего-либо в течение хода
💡 Продуктивность можно поднять улучшением
Тип улучшения ImprovementProductivityWorkshop из upgrades/ даёт «+ к производительности мастерских». Коэффициент задаётся в параметре Bonus.
🔗 Связанные разделы
  • Goods — исходные товары и результаты
  • Buildings — Type=Workshop, RequiredBuildings
  • Upgrades — ImprovementProductivityWorkshop
  • Settings.ini — стоимость и продуктивность модификации
  • Main.ini — [Group-Resources] (склад), [Units-About] (что на вооружении)
  • Main.ini → [ProcessedItemCount] — произведённая амуниция на текущем ходу
  • Лимиты движка — 2 входных слота
