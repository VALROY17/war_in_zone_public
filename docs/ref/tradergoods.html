🛒 Настройки ассортимента торговцев (TraderGoods.ini)

В данном файле определяется, у какого торговца продаётся ресурс/товар/предмет. Каждый блок [ТехническоеНазваниеРесурса] описывает один товар, а внутри перечисляются торговцы и группировки, у которых он доступен.

⚠️ Формат ключей: Группировка-Идеология
Ключи вида Stalkers-Crime, Duty-AntiZone — это техническое название группировки + дефис + техническое название идеологии.

Формат файла

[ТехническоеНазваниеРесурса]
World = True/False
TraderX = True/False
GroupX-IdeologyY = True/False

Параметры

КлючОписание
World Торговец «Внешний мир». Если True, то у торговца «Внешний мир» появляется данный товар. Этот торговец доступен всем группировкам и нет требований к владению какой-либо территорий
TraderX Торговец из Traders.ini. X — номер торговца (например, Trader1, Trader2). Соответствует секциям [Trader1], [Trader2] в Traders.ini
GroupX-IdeologyY Торговец группировки X с идеологией Y. X — техническое название группировки из Groups/ (например, Stalkers, Duty, Freedom).
Y — техническое название идеологии из ideologies/ (например, Crime, AntiZone, Anarchy, Stalkers, Unknow)
💡 Торговцев с False можно не указывать
Если торговец не должен продавать товар (значение False), эту строку можно просто не писать. Движок по умолчанию считает False.

Как добавить новый товар в ассортимент — чек-лист

  1. Создайте файл товара в Goods/ (например, MyWeapon.ini)
  2. Откройте TraderGoods.ini в вашем сценарии (или скопируйте из data\default\)
  3. Добавьте блок с техническим названием товара: [MyWeapon]
  4. Укажите, у каких торговцев он доступен (World=True, Trader1=True, Stalkers-Crime=True и т.д.)
  5. Добавьте локализацию в messages.csv: [Goods.MyWeapon].Name и Desc

Идеология «Unknow»

🔍 Что означает Unknow
В файлах часто встречается ключ GroupX-Unknow (например, Stalkers-Unknow, Bandits-Unknow).

Это «неизвестная идеология» — используется для группировок, у которых идеология не определена явно, или для начального состояния до смены идеологии. Если в вашем моде все группировки имеют чёткую идеологию, можете игнорировать Unknow-варианты.

Частые ошибки

⚠️ Типичные проблемы
  • Товар не появляется в магазине — проверьте, что он указан в TraderGoods.ini с правильным техническим названием (совпадает 1:1 с именем файла в Goods/)
  • Опечатка в названии группировки или идеологии — используйте точные названия из файлов Groups/ и ideologies/
  • Забыли добавить локализацию — без записей в messages.csv товар будет отображаться как техническое название
  • Торговец недоступен игроку — проверьте параметры торговца

Связь с другими файлами

ФайлСвязь
Goods/ Технические названия ресурсов в блоках [...] берутся отсюда. Название блока должно точно совпадать с именем файла в Goods/
Traders.ini Номера торговцев Trader1, Trader2 соответствуют секциям [Trader1], [Trader2] в Traders.ini. Параметры Coef-Sell-X, Coef-Buy-X определяют наценку/скидку
Groups/ Технические названия группировок (Stalkers, Duty и т.д.). Параметры CanTradeIf* определяют, может ли группировка торговать
ideologies/ Технические названия идеологий (Crime, AntiZone и т.д.)
Main.ini [Group-Ideology] — стартовая идеология группировки, [Group-Ideology-Percent] — распределение идеологий
messages.csv Локализация товаров: [Goods.ТехНазвание].Name и Desc
🔗 Связанные разделы
  • Goods — технические названия товаров
  • Traders.ini — параметры торговцев
  • Groups — технические названия группировок
  • Ideologies — технические названия идеологий
  • Main.ini — [Group-Ideology], [Group-Ideology-Percent]
  • messages.csv — локализация товаров
