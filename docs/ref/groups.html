⚔ Группировки (Groups)

Папка Groups\ в сценарии состоит из ini-файлов, каждый из которых представляет одну группировку. Название файла — техническое название группировки, которое используется в других конфигах.

⚠️ Секции в файле
Каждый файл содержит секцию [:main] (основные параметры) плюс по одной секции на каждую идеологию ([Stalkers], [AntiZone], [Crime] и т.д.). Добавили новую идеологию — придётся дописать секцию в каждой группировке, где она может стать основной.

Локализация (размещать в messages.csv)

[Groups.<техническое название>.:main].Name              - общее название группировки
[Groups.<техническое название>.:main].Description       - общее описание
[Groups.<техническое название>.<идеология>].Name        - название при этой идеологии
[Groups.<техническое название>.<идеология>].Description - описание при этой идеологии

🏝 Ограничения действий на анклавах

Группа из 18 параметров, управляющих тем, что разрешено делать на анклавах (изолированных территориях, не имеющих связи с основной территорией группировки) в зависимости от действующего внутреннего правила централизации.

Тип значения у всех: @@ЧИСЛА 1-5 — перечень индексов правил (1 = максимальная децентрализация, 5 = максимальная централизация), при которых действие отключается.

Ограничиваемое действие Анклавы в тылу врага
…ForEnemyEnclave		 Анклавы в тылу нейтрала
…ForNeutralEnclave		 Анклавы в тылу союзника
…ForSemiEnclave
Автопоиск артефактов RulesBranchWithDisabledAutoSearchForEnemyEnclave RulesBranchWithDisabledAutoSearchForNeutralEnclave RulesBranchWithDisabledAutoSearchForSemiEnclave
Ручной поиск артефактов RulesBranchWithDisabledManualSearchForEnemyEnclave RulesBranchWithDisabledManualSearchForNeutralEnclave RulesBranchWithDisabledManualSearchForSemiEnclave
Найм бойцов RulesBranchWithDisabledRecruitingForEnemyEnclave RulesBranchWithDisabledRecruitingForNeutralEnclave RulesBranchWithDisabledRecruitingForSemiEnclave
Возможность строить RulesBranchWithDisabledBuildingForEnemyEnclave RulesBranchWithDisabledBuildingForNeutralEnclave RulesBranchWithDisabledBuildingForSemiEnclave
Возможность атаковать с анклава RulesBranchWithDisabledAttackingFromForEnemyEnclave RulesBranchWithDisabledAttackingFromForNeutralEnclave RulesBranchWithDisabledAttackingFromForSemiEnclave
Передислокация RulesBranchWithDisabledArmyMoveForEnemyEnclave RulesBranchWithDisabledArmyMoveForNeutralEnclave RulesBranchWithDisabledArmyMoveForSemiEnclave
💡 Пример
RulesBranchWithDisabledBuildingForEnemyEnclave=1,2 — при правилах максимальной и обычной децентрализации строить на своих анклавах в тылу врага нельзя. При правилах 3, 4, 5 — можно.

Чтобы отключить действие для всех правил централизации, укажите полный перечень: 1,2,3,4,5.
