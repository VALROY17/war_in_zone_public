🤖 ИИ компьютерных противников (AI.ini)

Файл AI.ini определяет поведение ботов в сценарии. Каждая группировка использует свой блок настроек ИИ, указанный в параметре AI файла Groups.

📊 Структура файла
Файл содержит один или несколько блоков [Название-ИИ] (например, [AI-Stalkers]). Каждый блок описывает логику поведения одной группировки.

Логическая последовательность (блоки действий)

Поведение бота состоит из последовательности логических блоков, которые выполняются по порядку.

ПараметрТипОписание
CountBlocks@@ЦЕЛОЕЧисло логических блоков в последовательности
BlockX@@ВЫБОРТип блока действий. X — порядковый номер (от 1 до CountBlocks)

Покупка юнитов — модификаторы количества

Все значения в таблице ниже — @@ДРОБНОЕ. Эти коэффициенты определяют, сколько бойцов бот будет нанимать на различные территории.

ПараметрОписание
BuyUnitForAtackMotivationModificatorБот будет нанимать бойцов для атаки, пока у соседней вражеской территории войск больше (войско соседа × этот коэффициент)
BuyBaseGuardBehindMotivationModificatorБот будет покупать бойцов для главной базы в тылу (число для остановки роста % активности × этот модификатор)
BuyBaseGuardFrontEnemyMotivationModificatorБот будет нанимать бойцов на главную базу на границе с врагом, пока у соседа войск больше (войско соседа × коэффициент)
BuyBaseGuardFrontNeutralMotivationModificatorТо же для границы с нейтралом
BuyBaseGuardFrontAlliesMotivationModificatorТо же для границы с союзником
BuyUnitForGarrisonMotivationModificatorБот будет нанимать бойцов для достижения требования числа бойцов для остановки роста % активности (число × модификатор)
BuyUnitForGuardBorderWithEnemyMotivationModificatorБот будет нанимать бойцов на границу с врагом, пока у соседа войск больше (войско соседа × коэффициент)
BuyUnitForGuardBorderWithNeutralMotivationModificatorТо же для границы с нейтралом
BuyUnitForGuardBorderWithAlliesMotivationModificatorТо же для границы с союзником

Покупка юнитов — приоритеты рангов

Все значения в таблице ниже — @@ЧИСЛА 1-4. Списки приоритета найма рангов (1 = новичок, 2 = опытный, 3 = ветеран, 4 = мастер).

ПараметрОписание
BuyBaseGuardFrontAllies-PriorityПриоритет найма рангов на базу, граничащую с союзником
BuyBaseGuardFrontNeutral-PriorityПриоритет найма рангов на базу, граничащую с нейтралом
BuyBaseGuardFrontEnemy-PriorityПриоритет найма рангов на базу, граничащую с врагом
BuyBaseGuardBehind-PriorityПриоритет найма рангов на базу в тылу
BuyUnitForAtack-PriorityПриоритет найма рангов для атаки. Если ранг не указан, он не нанимается!
BuyUnitForGuardBorderWithEnemy-PriorityПриоритет найма рангов на границу с врагом
BuyUnitForGuardBorderWithNeutral-PriorityПриоритет найма рангов на границу с нейтралом
BuyUnitForGuardBorderWithAllies-PriorityПриоритет найма рангов на границу с союзником
BuyUnitForGarrison-PriorityПриоритет найма рангов в тыл. Если ранг не указан, он не нанимается!
⚠️ Осторожно с приоритетами
Если в списке приоритета отсутствует какой-то ранг (например, 1,2,3 без 4), бот никогда не наймёт мастеров для этого действия. Обычно рекомендуется указывать все 4 ранга: 1,2,3,4.

Покупка улучшений (блок BuyUpgrades)

ПараметрТипОписание
Upgrades-Index-Count@@ЦЕЛОЕСколько улучшений бот будет пытаться купить
Upgrades-Index-X@@НАЗВАНИЕТехническое название улучшения (имя файла без .ini), которое бот будет покупать (где X — порядковый номер)
Upgrades-LockPass@@BOOLЕсли True, бот не будет пытаться купить другое улучшение, если не хватает ресурсов на указанное в списке
⚠️ Заблокированные улучшения
Если бот попытается купить улучшение из ExcludedUpgrades в Settings.ini, игра выдаст ошибку на ходе бота. Убедитесь, что все улучшения в списке доступны.

Если бот попытается купить сооружение из ExcludedBuildings в Settings.ini, игра выдаст ошибку на ходе бота. Убедитесь, что все сооружения в списке доступны.

🔗 Где ещё используется
  • Groups → параметр AI — указывает, какой блок ИИ использует группировка
  • Advisors.ini — кандидаты для Advisor-TargetName
  • Buildings — названия построек для MainBaseBuildings, BorderBuildings
  • Upgrades — названия улучшений для Upgrades-Index-X
  • SpecialEvents — блок BrainControl управляет пси-установками
  • Settings.ini — ExcludedUpgrades, ExcludedBuildings (блокировка)
