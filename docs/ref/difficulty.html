🎯 Настройка сложности (Difficulty.ini)

Файл Difficulty.ini определяет стартовые бонусы и штрафы для игрока и бота в зависимости от выбранного уровня сложности. Файл содержит 8 жёстко закодированных секций (4 для игрока + 4 для бота).

⚠️ Названия секций — хардкод
Технические названия в [] нельзя переименовывать, так как они захардкожены в движке. Также нельзя добавлять новые секции. Можно только изменять значения параметров внутри существующих секций. См. Лимиты движка.

Как это работает в игре

При старте сценария игрок выбирает уровень сложности в меню. Движок берёт значения из соответствующей секции:

  • Для игрока — из секций [Novice-Player], [Skilled-Player], [Veteran-Player], [Master-Player]
  • Для ботов — из секций [Novice-AI], [Skilled-AI], [Veteran-AI], [Master-AI]

Значения прибавляются к стартовым ресурсам группировки, заданным в Main.ini → [Group-Resources].

💡 Пример для игрока новичка
; Файл: Difficulty.ini
[Novice-Player]
AddMoney=500
AddComands=10
AddSupplies=200
AddMedic=20
AddFood=100
AddLowArts=2
AddMediumArts=1
AddHighArts=0
AddLowParts=0
AddMediumParts=0
AddHighParts=0
AddNovice=10
AddSkilled=5
AddVeteran=2
AddMaster=1

Как изменить сложность сценария — чек-лист

  1. Скопируйте Difficulty.ini из data\default\ в папку вашего сценария
  2. Откройте файл и измените значения параметров в нужных секциях
  3. Сохраните в кодировке UTF-8 с BOM
  4. Протестируйте сценарий на разных уровнях сложности
⚠️ Не меняйте названия секций
Если вы измените название секции (например, [Novice-Player] → [Easy-Player]), движок не найдёт нужные значения и будет использовать нули.
💡 Совет по балансу
  • Novice — щедрые бонусы для новичков (много денег, ресурсов, рекрутов)
  • Skilled — умеренные бонусы
  • Veteran — нейтральный уровень (все нули — стартовые ресурсы только из Main.ini)
  • Master — штрафы для опытных игроков (отрицательные значения)

Связь с достижениями

В Achievements.ini параметр DifficultyLevel позволяет требовать определённый уровень сложности для получения ачивки. Значения: Any, Novice, Skilled, Veteran, Master.

🔗 Связанные разделы
  • Main.ini → [Group-Resources] — базовые стартовые ресурсы
  • Achievements.ini — DifficultyLevel
  • Лимиты движка — 8 жёстко закодированных секций
