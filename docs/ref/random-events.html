🎲 Случайные события (RandomEvents)

Папка RandomEvents\ в сценарии состоит из ini-файлов, каждый из которых представляет одно случайное событие. Каждый файл содержит один блок [Main].

⚠️ Нет привязки к территории
Все случайные события не имеют параметра Zona, так как случайные события всегда происходят на случайной территории. Это главное отличие от Events_Story.ini, где каждое событие привязано к конкретной территории.
💡 Случайность значения
Числовые эффекты задаются диапазоном: CountMin … CountMax. Игра сама выбирает значение внутри диапазона при срабатывании события.

Локализация (размещать в messages.csv)

[RandomEvents.<техническое название>].Name      - краткое название ивента
[RandomEvents.<техническое название>].Desc-YES  - текст описания в случае, если ивент смог отработать
[RandomEvents.<техническое название>].Desc-NO   - текст описания в случае, если ивент НЕ смог отработать
💡 Логика Desc-Yes / Desc-No и SoundFXForOwner / SoundFXForNonOwner
Эти параметры работают по условию. Если у фракции есть ресурс, на который направлено событие (например, кража или находка), срабатывает Desc-YES и SoundFXForOwner. Если ресурса нет — срабатывает Desc-NO и SoundFXForNonOwner.

Пример: Событие кражи артефактов. Если у фракции есть артефакты — срабатывает «Owner» (кража успешна). Если артефактов нет — срабатывает «NonOwner» (украсть нечего).
📌 Включаются в Settings.ini
EventsRandomDefault — состояние по умолчанию в меню,
EventsRandomCanChange — может ли игрок их отключить перед стартом. См. Settings.ini.

Типы ивентов (всего 22)

Движок поддерживает ровно 22 типа случайных событий — это жёсткий лимит. В дефолтном сценарии используется только 8 из них, остальные 14 доступны для мододелов.

RandomEvents vs Events_Story

Возможность🎲 RandomEvents📖 Events_Story
Привязка к территории (Zona)❌ нет — всегда случайная✅ обязательна для каждого события
Привязка к ходу (Step)❌ нет✅ есть (0 или пусто = вневременное)
Повторяемость (Repeatable)❌ нет✅ есть (только при Step=0)
Ивент-флаги❌ нет✅ EventFlag, EventFlagResult и др.
Числовой эффект🎲 часто диапазон CountMin…CountMax🔢 только точное значение
Проверочные типы (Check*)❌ нет✅ 7 типов
Типы с ГГ (MCMove, MCAttack)❌ нет✅ есть
🔗 Связанные разделы
  • Events_Story.ini — сюжетные события (35 типов, флаги, привязка к территории)
  • SpecialEvents — глобальные механики (Выброс, пси-излучение и т.д.)
  • Settings.ini — EventsRandomDefault, EventsRandomCanChange
  • Buildings · Leaders · Advisors.ini · Ideologies · Upgrades — цели для BuildingName, NewLeader и др.
  • messages.csv — ключи [RandomEvents.*]
  • Лимиты движка — 22 типа захардкожены, добавить новый нельзя
