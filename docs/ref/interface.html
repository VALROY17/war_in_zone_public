🎨 Настройки игрового интерфейса (interface.ini)

Файл interface.ini отвечает за изображения кнопок, значков, фонов и звуков игрового интерфейса. Через него можно перерисовать практически всю графику UI под стиль своего сценария.

Механизм наследования (главная особенность)

💡 Не копируйте весь файл!
Для того чтобы изменить один значок в своём сценарии, нет необходимости полностью копировать файл к себе. Достаточно:
  1. Создать в папке своего сценария файл interface.ini
  2. Добавить в него только ту секцию и тот параметр, который хочется изменить
Движок автоматически подгрузит остальные значения из data\default\interface.ini.

Пример: замена фона меню найма бойцов

; Файл: МойСценарий\interface.ini
[Graphics-In-game]
BuyUnits-Fon=gfx\ui\my_scenario\buy_units_background.png

Всё! Остальные параметры фона, кнопок и звуков будут взяты из дефолтного файла.

Пример: замена нескольких элементов

; Файл: МойСценарий\interface.ini
[Graphics-In-game]
BuyUnits-Fon=gfx\ui\my_scenario\buy_units.png
Recruit-Fon=gfx\ui\my_scenario\recruit.png
Diplomacy-Fon=gfx\ui\my_scenario\diplomacy.png

[Graphics-BTN-Standart]
Button-OK=gfx\ui\my_scenario\btn_ok.png
Button-Cancel=gfx\ui\my_scenario\btn_cancel.png

[Sounds]
ClickButton=sfx\ui\my_click.wav

Где находится полный список параметров

Полный список всех доступных параметров и их дефолтных значений находится в файле:

data\default\interface.ini

Откройте его в текстовом редакторе, чтобы увидеть все секции и параметры, которые можно переопределить в своём сценарии.

Секции, актуальные для сценария

Хотя в дефолтном файле много секций, для большинства сценариев важны только эти 6:

СекцияЧто содержит
[Graphics-In-game] Фоны внутриигровых окон (меню найма бойцов, дипломатии, склада, разведки и т.д.), иконки ресурсов, элементов управления
[MultiTexture] Составные текстуры, атласы изображений, используемые в разных частях интерфейса
[Graphics-BTN-Standart] Изображения кнопок в обычном состоянии (без наведения)
[Graphics-BTN-Active] Изображения кнопок при наведении курсора
[Graphics-RadioBTN] Переключатели (radio buttons), чекбоксы и подобные элементы
[Sounds] Звуки интерфейса: клики кнопок, открытие/закрытие окон, уведомления

Как перерисовать интерфейс — чек-лист

  1. Откройте data\default\interface.ini и изучите, какие параметры отвечают за нужные элементы интерфейса
  2. Найдите в data\default\gfx\ оригинальные изображения — по ним можно понять требуемые размеры и стиль
  3. Создайте свои изображения, соблюдая размеры оригиналов (иначе элементы интерфейса «поедут»)
  4. Создайте файл interface.ini в папке своего сценария
  5. Укажите только те секции и параметры, которые нужно переопределить
  6. Разместите свои изображения в папке gfx\ вашего сценария (или в общей data\gfx\)
  7. Протестируйте сценарий — убедитесь, что элементы интерфейса отображаются корректно

Практические советы

⚠️ Сохраняйте размеры оригиналов
Если оригинальная кнопка имеет размер 120×40 пикселей, ваша замена должна быть такого же размера. Иначе кнопка может:
  • Растянуться или сжаться
  • Перекрыть соседние элементы
  • Оставить пустые области вокруг
💡 Единый стиль
При создании собственного UI придерживайтесь единой цветовой палитры и стиля. Смешение стилей (например, пиксель-арт рядом с фотореалистичными текстурами) выглядит неаккуратно.
💡 Используйте прозрачность
Формат PNG с альфа-каналом позволяет создавать элементы с прозрачным фоном — это особенно полезно для кнопок и иконок, которые должны органично вписываться в разные фоны.
💬 Не нашли нужный параметр?
Если в справке нет описания конкретного параметра interface.ini, откройте дефолтный файл data\default\interface.ini — там все параметры с комментариями. Если всё равно непонятно — спрашивайте в Discord-сообществе игры.
