🖼 Фоновые иконки объектов на карте (BackgroundObjects.ini)

Файл содержит список декоративных (некликабельных) объектов на глобальной карте сценария. Находится в папке сценария рядом с другими файлами карты.

💡 Что такое декоративный объект»
Это чисто декоративная иконка на глобальной карте: она не является территорией, не взаимодействует с игроком и ни на что не влияет в игровом процессе. Подходит для визуальных отметок — например, знака радиации, аномалии, руин или любого другого атмосферного элемента.

Параметры

Секция / ПараметрТипОписание
[Main] → Count@@ЦЕЛОЕКоличество декоративных объектов в файле. Должно точно совпадать с числом блоков [Element<X>]
[Element<X>] → X@@ЦЕЛОЕГоризонтальная координата объекта в пикселях (от левого края текстуры карты)
[Element<X>] → Y@@ЦЕЛОЕВертикальная координата объекта в пикселях (от верхнего края текстуры карты)
[Element<X>] → Name@@ПУТЬОтносительный путь к файлу изображения (PNG). Например, gfx\Elements\GlobalMap\anomaliesVulkan.agr

Где <X> — порядковый индекс объекта (от 1 до значения Count).

Пример структуры

[Main]
Count=2

[Element1]
X=120
Y=340
Name=gfx\Elements\GlobalMap\anomaliesVulkan.agr

[Element2]
X=880
Y=210
Name=gfx\Elements\GlobalMap\DarkRuins.png
⚠️ Что будет, если Count не совпадёт
  • Если число в Count больше реального количества блоков [Element<X>] — игра выдаст ошибку при загрузке сценария
  • Если число меньше реального — движок просто прочитает столько элементов, сколько указано в Count, остальные проигнорирует
Индексы элементов должны идти строго подряд, начиная с 1.
🔗 Связанные разделы
  • Файлы карты — основные файлы глобальной карты
  • Territories_Icon_Coordinates.ini — координаты логотипов группировок на территориях
  • Изображение карты — текстура глобальной карты, относительно которой задаются координаты
  • Кодировка файлов — UTF-8 с BOM
