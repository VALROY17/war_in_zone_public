📦 Амуниция, ресурсы, товары (Goods)

Папка Goods\ в сценарии состоит из ini-файлов, каждый из которых представляет один товар, ресурс или предмет экипировки. Название файла — техническое название товара, которое используется в других конфигах. Каждый файл содержит один блок [Main].

Локализация (размещать в messages.csv)

[Goods.<техническое название>].Name   - название, отображаемое в игре
[Goods.<техническое название>].Desc   - текстовое описание товара

Общие параметры (для всех типов товаров)

ПараметрТипОписание
Img@@ПУТЬПуть к изображению товара (используется в торговле, на складе, в рецептах)
Type@@ВЫБОРТип товара. Возможные значения:
• Weapon — оружие
• Armor — броня
• Resource — ресурс/товар общего назначения
Cost@@ЦЕЛОЕБазовая денежная цена товара без учёта коэффициентов торговцев
Category@@ТЕКСТКатегория товара для регулировки множителей цены у торговцев. Можно использовать стандартные или создавать собственные. См. Traders.ini
SortOrder@@ЦЕЛОЕПорядок отображения в списках (чем меньше значение, тем выше в списке)
🏷 Стандартные категории
В оригинальных конфигах используются следующие категории: Food, Medic, Supplies, Parts, Arts, Weapon, Armor, BuildingMaterials, AmmoComponents. Множители цен по категориям настраиваются в Traders.ini (параметры Coef-Sell-X, Coef-Buy-X).

⚔ Параметры оружия (Type=Weapon)

ПараметрТипОписание
PVP@@ЦЕЛОЕУрон по другим сталкерам (базовое значение)
PVM@@ЦЕЛОЕУрон по мутантам (базовое значение)
Range@@ЦЕЛОЕДальность атаки
Consum@@ЦЕЛОЕРасход боеприпасов за одну атаку
Level@@ЦЕЛОЕМинимальный ранг бойца для использования этого оружия:
1 = новичок, 2 = опытный, 3 = ветеран, 4 = мастер

🛡 Параметры брони (Type=Armor)

ПараметрТипОписание
PVP@@ЦЕЛОЕЗащита от урона других сталкеров
PVM@@ЦЕЛОЕЗащита от урона мутантов
AntiRad@@ЦЕЛОЕЗащита от радиации, выброса и аномалий
Mass@@ЦЕЛОЕВес брони (штраф к мобильности). Чем больше значение, тем сильнее снижается мобильность бойца
Level@@ЦЕЛОЕМинимальный ранг бойца для использования этой брони:
1 = новичок, 2 = опытный, 3 = ветеран, 4 = мастер

💊 Параметры ресурсов (Type=Resource)

У обычных ресурсов (еда, медикаменты, артефакты, части мутантов) обычно нет дополнительных параметров помимо общих. Их эффекты задаются через другие системы:

  • Еда — параметр FoodName в Settings.ini указывает, какой товар считается едой
  • Медикаменты — параметр MedicName в Settings.ini
  • Припасы — параметр SuppliesName в Settings.ini

Как добавить новое оружие — чек-лист

  1. Создайте ini-файл в папке Goods\ сценария (если папки нет — создайте). Имя файла = техническое название оружия
  2. Заполните блок [Main]: общие параметры + параметры оружия
  3. Добавьте строки локализации в messages.csv
  4. Пропишите стартовое количество на складе в Main.ini → [Group-Resources] (если = 0, то прописывать не обязательно)
  5. Назначьте оружие шаблону юнита в Main.ini → [Units-About] (Шаблон-Weapon=ТехНазвание)
  6. Дайте торговцам возможность продавать это! — добавьте товар в TraderGoods.ini

Стоимость найма юнита

📊 Формула из Settings.ini
Цена юнита = цена оружия + цена брони + ранг × UnitCostModificator
Параметр Cost из этого конфига напрямую влияет на стоимость найма бойца. UnitCostModificator настраивается в Settings.ini.
💡 Пример: создание нового оружия
; Файл: Goods\MyCustomRifle.ini
[Main]
Img=gfx\icons\goods\SVD.png
Type=Weapon
Cost=5000
Category=Weapon
SortOrder=100
PVP=45
PVM=30
Range=8
Consum=2
Level=3
🔗 Где ещё используется
  • Main.ini — [Group-Resources] (стартовые запасы), [Units-About] (экипировка юнитов)
  • TraderGoods.ini — ассортимент торговцев
  • Traders.ini — Coef-Sell-X/Coef-Buy-X по Category
  • Receipts — модернизация через мастерскую
  • Buildings — Custom-Resource, ProductionNameFrom/To
  • Difficulty.ini — стартовые артефакты и части мутантов
  • Settings.ini — MedicName, SuppliesName, FoodName, UnitCostModificator
  • Events_Story.ini — типы событий AddWeapon, RemoveWeapon, AddArmor, RemoveArmor
