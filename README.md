## 🌿 Ветки репозитория

| Ветка | Назначение | Для кого |
|-------|-----------|----------|
| `main` | Стабильные пре-релизные версии (входят в установщик игры) | Игроки |
| `qa` | Тестовые кандидаты будущих релизов, полировка и багфикс | Тестировщики, моддеры |
| `dev` | Активная разработка, нестабильные сборки | Разработчики |

> Контент проходит путь: `dev` → `qa` → `main`. Только после тестирования и стабилизации изменения попадают в публичные релизы.
