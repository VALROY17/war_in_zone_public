**WAR IN ZONE** is a global turn-based strategy game set in the S.T.A.L.K.E.R. universe, focused on faction warfare.  
[📖 Modding Help](./ModdingHelp.html)

## ⬇️ Download and Installation
To start playing, you don't need to build the project manually. 
1. Download the official **WAR IN ZONE Launcher** from the [Releases](https://github.com/VALROY17/war_in_zone_public/releases) section (or via the link in our [Discord](https://discord.gg/vyG7rWYxuP)).
2. Run the launcher. It will automatically find the latest stable version of the game and help you install it.
> *Please do not close the launcher while downloading updates!*

---

## 🖥 System Requirements
* **OS:** Windows 7 / 8 / 10 / 11 (32-bit / 64-bit)
* **Processor:** Pentium E2140 (or any dual-core processor)
* **RAM:** 1 GB RAM
* **Storage:** 2 GB available space
* **Internet:** Required for downloading the game via the launcher and for multiplayer.

## 🌿 Repository Branches

| Branch | Purpose | Audience |
|--------|---------|----------|
| `main` | Stable pre-release versions (included in the game installer) | Players |
| `qa` | Release candidates for future updates, polishing, and bug fixes | Testers, Modders |
| `dev` | Active development, unstable builds | Developers |

> Content flows through: `dev` → `qa` → `main`. Changes only reach public releases after testing and stabilization.

# Публичный репозиторий игры 🎮 WAR IN ZONE

**WAR IN ZONE** — глобальная пошаговая стратегия в сеттинге вселенной S.T.A.L.K.E.R. с тематикой войны группировок.  
[📖 Помощь мододелам](./ModdingHelp.html)

## ⬇️ Скачивание и установка
Чтобы начать играть, вам не нужно собирать проект вручную. 
1. Скачайте официальный **Лаунчер WAR IN ZONE** из раздела [Releases](https://github.com/VALROY17/war_in_zone_public/releases) (или по ссылке из нашего [Discord](https://discord.gg/vyG7rWYxuP)).
2. Запустите лаунчер. Он автоматически найдёт последнюю стабильную версию игры и поможет её установить.
> *Пожалуйста, не закрывайте лаунчер во время скачивания обновлений!*

---

## 🖥 Системные требования
* **ОС:** Windows 7 / 8 / 10 / 11 (32-bit / 64-bit)
* **Процессор:** Pentium E2140 (или любой двухъядерный процессор)
* **Оперативная память:** 1 GB RAM
* **Место на диске:** 2 GB
* **Интернет:** Требуется для загрузки игры через лаунчер и мультиплеера.

## 🌿 Ветки репозитория

| Ветка | Назначение | Для кого |
|-------|-----------|----------|
| `main` | Стабильные пре-релизные версии (входят в установщик игры) | Игроки |
| `qa` | Тестовые кандидаты будущих релизов, полировка и багфикс | Тестировщики, моддеры |
| `dev` | Активная разработка, нестабильные сборки | Разработчики |

> Контент проходит путь: `dev` → `qa` → `main`. Только после тестирования и стабилизации изменения попадают в публичные релизы.
